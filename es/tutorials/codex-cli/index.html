Codex CLI

El agente de terminal oficial de OpenAI.

Codex usa la API compatible con OpenAI, así que puede hablar con más que api.openai.com. Usa tu clave de OpenAI directamente o declara un proveedor propio en el archivo de configuración.

Documentación oficial ↗

Pasos de configuración

  1. 1

    Instala la CLI

    Requiere Node.js 18 o posterior. Instala el comando global codex.

    bash
    npm install -g @openai/codex
  2. 2

    Opción A: usa tu clave de OpenAI

    Configura tu clave desde la plataforma de OpenAI. Reabre la terminal tras setx en Windows.

    bash / zsh
    export OPENAI_API_KEY="your-api-key"
    PowerShell
    setx OPENAI_API_KEY "your-api-key"
  3. 3

    Opción B: añade un proveedor propio

    Declara un endpoint compatible con OpenAI en el archivo de configuración. env_key indica la variable de entorno con la clave; wire_api = chat va bien para la mayoría de endpoints de terceros.

    ~/.codex/config.toml
    model = "your-model-name"
model_provider = "custom"

[model_providers.custom]
name = "Custom"
base_url = "https://api.example.com/v1"
env_key = "OPENAI_API_KEY"
wire_api = "chat"
  4. 4

    Borra un inicio de sesión de ChatGPT guardado

    Solo si antes iniciaste sesión con ChatGPT. Esto obliga a Codex a usar tu propia clave.

    bash
    codex logout
  5. 5

    Empieza a programar

    Ejecútalo dentro de la carpeta de tu proyecto y empieza a dar instrucciones.

    bash
    codex
Consejo: Si iniciaste sesión con ChatGPT, ejecuta primero codex logout y luego elige «Provide your own API key» en el siguiente arranque para que use tu proveedor propio.
Elige primero un modelo o proveedor más barato y luego introduce su clave y endpoint en los pasos de arriba. Comparar precios · Ver proveedores
