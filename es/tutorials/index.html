Guías de configuración CLI

Conecta las herramientas de programación con IA de línea de comandos a cualquier API en unos pasos. Copia, pega y sustituye los marcadores por tu propia clave y endpoint. Listo.

Las 3 cosas que necesita cada herramienta

Clave API

Un token secreto que demuestra quién eres y contra el que se factura. Mantenlo privado y nunca lo subas a git.

URL base

El endpoint con el que habla la herramienta. Cámbialo para enrutar por un proveedor más barato en lugar del predeterminado.

Nombre del modelo

Qué modelo ejecutar, exactamente como lo nombra tu proveedor, p. ej. el id de modelo que aparece en su página de precios.

Ajuste el formato del endpoint a la herramienta. Codex CLI, Aider, opencode y Qwen Code aceptan directamente un endpoint compatible con OpenAI. Claude Code usa el formato de Anthropic, así que apunte ANTHROPIC_BASE_URL a un endpoint compatible con Anthropic o a un conversor. Gemini CLI es nativo de Google.
