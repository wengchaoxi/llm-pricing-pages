Qwen Code

Agente de código abierto optimizado para Qwen, compatible con OpenAI.

Qwen Code lee tres variables de entorno para el acceso compatible con OpenAI: la clave, la URL base y el modelo. Con eso basta para apuntarlo a cualquier proveedor compatible.

Documentación oficial ↗

Pasos de configuración

  1. 1

    Instala Qwen Code

    Requiere Node.js 20 o posterior. Instala el comando global qwen.

    bash
    npm install -g @qwen-code/qwen-code
  2. 2

    Configura las tres variables

    Indica tu clave, la URL del endpoint y el id del modelo. En Windows usa setx y reabre la terminal.

    bash / zsh
    export OPENAI_API_KEY="your-api-key"
export OPENAI_BASE_URL="https://api.example.com/v1"
export OPENAI_MODEL="your-model-name"
  3. 3

    Empieza a programar

    Ejecútalo dentro de la carpeta de tu proyecto para empezar a trabajar con el modelo.

    bash
    qwen
Consejo: Funciona con DashScope, OpenRouter, ModelScope y servidores propios: cualquier cosa que exponga un endpoint compatible con OpenAI.
Elige primero un modelo o proveedor más barato y luego introduce su clave y endpoint en los pasos de arriba. Comparar precios · Ver proveedores
