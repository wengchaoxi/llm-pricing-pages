Precios de suscripciones IA

Precios y cupos de los planes de ChatGPT, Claude, Gemini y otras suscripciones de IA de consumo. Se facturan por usuario y mes, un eje distinto del precio por token de las API. Dentro de cada proveedor, los planes se ordenan por precio.

Los precios y límites son información pública recopilada el 2026-10-22 y no verificada con cada proveedor por separado. Los planes cambian a menudo; la página oficial tiene prioridad. Para sopesar una suscripción frente a la API de pago por uso, utilice la Calculadora de suscripción vs API →
