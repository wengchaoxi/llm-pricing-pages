opencode

Agent terminal open source, fonctionne avec tout fournisseur.

opencode configure chaque fournisseur avec une URL de base plutôt que de lire OPENAI_BASE_URL. Le plus rapide est la connexion interactive ; pour un contrôle total, modifiez le fichier de configuration.

Docs officielles ↗

Étapes de configuration

  1. 1

    Installez opencode

    Nécessite Node.js 18 ou plus récent. Installe la commande globale opencode.

    bash
    npm install -g opencode-ai
  2. 2

    Option A : connexion rapide

    Exécutez la commande de connexion, descendez jusqu'à « Other », puis collez votre URL de base et votre clé API.

    bash
    opencode auth login
  3. 3

    Option B : fichier de configuration

    Déclarez un fournisseur compatible OpenAI avec son URL de base, sa clé et son modèle. Remplacez les valeurs par les vôtres.

    ~/.config/opencode/opencode.json
    {
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "custom": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.example.com/v1",
        "apiKey": "your-api-key"
      },
      "models": { "your-model-name": {} }
    }
  }
}
  4. 4

    Commencez à coder

    Lancez-le dans le dossier de votre projet et sélectionnez votre modèle personnalisé avec la commande /models.

    bash
    opencode
Astuce : opencode ne lit pas OPENAI_BASE_URL ni OPENAI_API_KEY pour les endpoints personnalisés. Vous devez déclarer le fournisseur, via auth login ou le fichier de configuration.
