Guides de configuration CLI

Connectez les outils de codage IA en ligne de commande à n'importe quelle API en quelques étapes. Copiez, collez, remplacez les espaces réservés par votre propre clé et endpoint. C'est fait.

Les 3 choses dont chaque outil a besoin

Clé API

Un jeton secret qui prouve votre identité et qui est facturé. Gardez-le privé, ne le commitez jamais dans git.

URL de base

L'endpoint avec lequel l'outil communique. Modifiez-le pour passer par un fournisseur moins cher au lieu de celui par défaut.

Nom du modèle

Quel modèle exécuter, exactement comme votre fournisseur le nomme, p. ex. l'id du modèle affiché sur sa page de tarifs.

Adaptez le format de l’endpoint à l’outil. Codex CLI, Aider, opencode et Qwen Code acceptent directement un endpoint compatible OpenAI. Claude Code utilise le format Anthropic : pointez ANTHROPIC_BASE_URL vers un endpoint compatible Anthropic ou un convertisseur. Gemini CLI est natif Google.
