आधिकारिकGemini / GoogleGoogle

Gemini CLI

Google का आधिकारिक टर्मिनल एजेंट।

सबसे तेज़ रास्ता Google AI Studio से एक API कुंजी है जिसे GEMINI_API_KEY के रूप में सेट किया जाता है। आप इसे बस लॉन्च करके मुफ़्त टियर के लिए अपने Google खाते से भी लॉग इन कर सकते हैं।

आधिकारिक डॉक्स ↗

सेटअप चरण

  1. 1

    CLI इंस्टॉल करें

    Node.js 20 या नया चाहिए। ग्लोबल gemini कमांड इंस्टॉल करता है।

    bash
    npm install -g @google/gemini-cli
  2. 2

    एक API कुंजी प्राप्त करें

    Google AI Studio में एक मुफ़्त कुंजी बनाएँ और उसे कॉपी करें।

    text
    https://aistudio.google.com/apikey
  3. 3

    कुंजी सेट करें

    इसे GEMINI_API_KEY पर्यावरण चर में संग्रहीत करें। सत्रों के बीच बनाए रखने के लिए इसे अपने शेल प्रोफ़ाइल में जोड़ें।

    bash / zsh
    export GEMINI_API_KEY="your-api-key"
    PowerShell
    setx GEMINI_API_KEY "your-api-key"
  4. 4

    कोडिंग शुरू करें

    चैट करने, कोड पढ़ने और संपादित करने के लिए इसे अपने प्रोजेक्ट फ़ोल्डर के अंदर चलाएँ।

    bash
    gemini
सुझाव: आज़माने के लिए कुंजी की ज़रूरत नहीं: gemini चलाएँ और किसी Google खाते से साइन-इन करें। अधिक सीमाओं और API बिलिंग के लिए GEMINI_API_KEY का उपयोग करें।
पहले कोई सस्ता मॉडल या प्रदाता चुनें, फिर उसकी कुंजी और एंडपॉइंट को ऊपर के चरणों में डालें। मूल्य तुलना करें · प्रदाता देखें
