CLI सेटअप गाइड

कमांड-लाइन AI कोडिंग टूल को कुछ ही चरणों में किसी भी API की ओर इंगित करें। कॉपी करें, पेस्ट करें, प्लेसहोल्डर को अपनी कुंजी और एंडपॉइंट से बदलें, हो गया।

हर टूल को चाहिए ये 3 चीज़ें

API कुंजी

एक गुप्त टोकन जो साबित करता है कि आप कौन हैं और जिस पर बिल लगता है। इसे निजी रखें, कभी git में कमिट न करें।

Base URL

वह एंडपॉइंट जिससे टूल बात करता है। डिफ़ॉल्ट के बजाय किसी सस्ते प्रदाता से रूट करने के लिए इसे बदलें।

मॉडल नाम

कौन-सा मॉडल चलाना है, ठीक वैसे जैसे आपका प्रदाता उसे नाम देता है, जैसे उसके मूल्य पृष्ठ पर दिखाया गया मॉडल आईडी।

एंडपॉइंट का प्रारूप टूल के अनुसार रखें। Codex CLI, Aider, opencode और Qwen Code सीधे OpenAI-संगत एंडपॉइंट लेते हैं। Claude Code Anthropic प्रारूप का उपयोग करता है, इसलिए ANTHROPIC_BASE_URL को Anthropic-संगत एंडपॉइंट या किसी कनवर्टर पर सेट करें। Gemini CLI गूगल-नेटिव है।
