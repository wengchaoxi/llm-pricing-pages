Claude Duet vs Grok Bot: 각각의 요금과 사용 한도 계산 방식

Claude Duet(Anthropic, 2026년 10월 21일부터 리서치 프리뷰)과 Grok Bot(xAI, 2026년 8월부터 초기 베타)은 각자의 클라우드 컴퓨터에서 실행되며, 앱을 닫은 뒤에도 작업을 이어 갑니다. 둘 다 행동하기 전에 승인을 요청합니다. 어느 쪽도 별도 제품으로 판매되지 않습니다. 각각 소비자용 구독에 포함되어 있으므로, 가격은 해당 에이전트를 이용할 수 있게 해 주는 요금제의 가격입니다.

핵심 요약

  • Claude Duet에는 자체 가격이 없습니다. Claude Pro(월 US$20.00)와 Claude Max(US$100.00 또는 US$200.00)에 포함되며, 대기자 명단 방식으로 미국 계정부터 제공됩니다.
  • Grok Bot은 Grok Premium(월 US$30.00), Super(US$100.00), Ultra(US$200.00)와 해당하는 Teams 및 Enterprise 요금제에 포함됩니다. Super와 Ultra는 주간 Grok Bot 사용량을 Premium 수준의 3.5배와 12배로 늘립니다.
  • 두 공급사 모두 절대적인 사용 상한을 공개하지 않습니다. Claude Duet은 Claude의 다른 기능과 같은 한도를 쓰고, Grok Bot의 사용량은 기준 등급의 배수로만 표기됩니다.
  • 최저 시작 가격: Claude Duet은 월 US$20.00인 Claude Pro, Grok Bot은 월 US$30.00인 Grok Premium입니다.

Claude Duet: 요금과 사용 한도

Anthropic은 Claude Duet을 전문직 종사자와 소규모 사업자를 위한 능동형 에이전트로 소개합니다. 매일 아침 짧은 브리핑을 보내고, 몇 시간마다 연결된 계정을 확인하며, 맡은 작업을 가상 머신에서 처리하므로 휴대폰이나 노트북을 계속 켜 둘 필요가 없습니다. 리서치 프리뷰 기간에는 추가 요금 없이 Pro와 Max에 포함되며, Claude의 다른 기능과 같은 사용 한도를 씁니다.

Anthropic에 따르면 백그라운드 확인은 요금제 한도에 포함되며, 그래서 Claude Duet은 계속 확인하지 않고 몇 시간마다 확인합니다. 재무 모델이나 슬라이드 자료 같은 큰 작업은 모델 턴이 더 많이 필요해 일반 대화보다 사용량을 더 씁니다. Claude Duet의 작업 수나 토큰 수에 대한 절대 수치는 공개되지 않았으므로, 실제 한도는 맡기는 백그라운드 작업의 양에 따라 달라집니다.

이용은 대기자 명단 방식이며 미국의 Pro 및 Max 사용자부터 시작됩니다. 발표는 이 계정들만 다루며, 다른 요금제나 지역에 대한 일정은 밝히지 않았습니다.

Claude Duet은 Claude Opus 5.5를 중심으로 설계되었습니다. Anthropic API에서 Opus 5.5의 정가는 100만 토큰당 입력 US$4.00, 출력 US$20.00이며, 캐시 읽기는 US$0.20입니다. 이는 입력 US$5.00, 출력 US$25.00인 Claude Opus 5보다 낮습니다.

Grok Bot: 요금과 사용 한도

xAI는 Grok Bot을 사용자의 도구에 로그인해 사용자처럼 도구를 쓰고 완성된 결과물을 돌려주는 AI 팀원으로 소개합니다. Bot은 계정의 모든 Bot이 공유하는 클라우드 컴퓨터에서 실행되고, 여러 Bot이 병렬로 일할 수 있으며, 한 번 시연한 워크플로는 일정에 따라 실행되는 루틴으로 저장할 수 있습니다.

xAI는 사용량을 절대 수치가 아닌 배수로 표기합니다. Grok Bot 페이지는 Super를 Premium의 3.5배, Ultra를 12배로 제시합니다. 가격 페이지는 대신 Plus를 기준으로 삼아 Premium을 Plus의 4배, Super를 15배로 표기하며, 이를 환산하면 Premium 대비 Super는 3.75배입니다. 두 페이지는 기준이 서로 다르며, Ultra는 Grok Bot 페이지에만 나옵니다.

Grok Bot은 해당하는 Teams 및 Enterprise 요금제에도 포함됩니다. 가격 페이지에는 월 US$8.00인 Plus 등급이 있지만, Grok Bot은 Premium 이상에만 표시됩니다.

Grok Bot 페이지는 기반 모델을 밝히지 않으며, 가격 페이지에는 Premium에 최신 Grok 모델이 포함된다고 나와 있습니다. 이 사이트 카탈로그에서 가장 최신 Grok 모델은 Grok 4.7로, 2026년 9월 21일에 출시되었으며 xAI API 정가는 100만 토큰당 입력 US$2.00, 출력 US$6.00입니다.

요금제 월 요금을 API 정가로 환산하면

요금제 월 요금은 모델의 API 가격을 적용해 토큰으로 환산할 수 있습니다. 이는 단위 환산이며 요금제가 제공하는 사용량이 아닙니다. 두 공급사 모두 요금제에 포함된 토큰 수를 공개하지 않기 때문입니다. 표는 이 사이트 전체에서 쓰는 혼합 단가(입력 75%, 출력 25%)를 사용하며, 캐시 할인은 반영하지 않습니다. 같은 컨텍스트를 반복해서 읽는 에이전트 루프에서는 캐시 할인이 비용을 낮춥니다.

백그라운드 작업이 계산을 바꾸는 이유

채팅 요금제는 사용자가 입력할 때 쓰입니다. 이 에이전트들은 사용자가 입력하지 않을 때도 요금제를 씁니다. Claude Duet은 몇 시간마다 연결된 계정을 확인하며, Anthropic은 계속 확인하면 요금제 한도가 훨씬 빨리 소진된다고 밝혔습니다. Grok Bot은 일정에 따라 루틴을 실행하고 여러 Bot을 동시에 돌릴 수 있으며, xAI는 이를 24시간 연중무휴로 일하는 것으로 설명합니다.

사용량이 얼마나 소진되는지는 활성화된 연결 앱이나 예약 루틴의 수와 각 작업의 크기에 따라 달라집니다. Anthropic은 재무 모델과 프레젠테이션을 무거운 작업으로 꼽습니다. xAI의 등급은 주로 주간 Grok Bot 사용량에서 차이가 나므로, 계속 일을 맡겨 두는 Bot의 수가 상위 등급으로 올릴 실질적인 이유가 됩니다.

상위 등급에 비용을 내기 전에 에이전트가 백그라운드에서 무엇을 하는지 확인하는 것이 좋습니다. 활성화된 루틴과 연결된 계정을 목록으로 정리해 보면 됩니다. Claude Duet에서는 무엇을 얼마나 자주 보고할지 설정할 수 있습니다.

그 밖의 상시 작동형 AI 에이전트

다른 소비자용 에이전트 세 가지도 같은 설계를 따릅니다. 사용자가 자리를 떠난 뒤에도 계속 일하는 클라우드 컴퓨터입니다. 세 제품 모두 Claude Duet보다 먼저 발표되었습니다. 상시 작동형 AI 에이전트 정리에서 다섯 제품을 모두 비교합니다.

어느 쪽이 맞을까

  • 미국에서 Claude Pro나 Max를 쓰고 있고 Claude 메모리, 스킬, 커넥터와 연결된 어시스턴트가 필요한 경우: Claude Duet은 프리뷰 기간에 추가 요금이 없으며 현재 한도 안에서 작동합니다.
  • 여러 에이전트의 병렬 작업, 시연으로 가르치는 루틴, 데스크톱 앱 가운데 하나가 필요한 경우: 월 US$30.00부터 이용할 수 있는 Grok Bot.
  • 가격만 비교하는 경우: US$20.00인 Claude Pro가 더 낮은 시작 가격이지만, Claude Duet은 대기자 명단 방식이고 미국에서 먼저 제공됩니다. US$30.00인 Grok Premium에는 Grok Bot이 포함되며, xAI 페이지에서는 요금제와 함께 다운로드할 수 있도록 안내합니다.

자주 묻는 질문

Claude Duet은 무료인가요?

별도 요금은 표시되어 있지 않습니다. 리서치 프리뷰 기간에 Claude Duet은 Claude Pro(월 US$20.00)와 Claude Max(US$100.00 또는 US$200.00)에 포함되고, Claude의 다른 기능과 같은 사용 한도를 쓰며, 대기자 명단을 통해 미국 사용자에게 먼저 제공됩니다.

Grok Bot은 얼마인가요?

Grok Bot은 Grok Premium(월 US$30.00), Super(US$100.00), Ultra(US$200.00)에 포함됩니다. xAI의 Grok Bot 페이지에 따르면 Super와 Ultra는 주간 사용량을 Premium 수준의 3.5배와 12배로 늘립니다. 해당하는 Teams 및 Enterprise 요금제에도 포함됩니다.

어떤 Claude 요금제에 Claude Duet이 포함되나요?

Anthropic의 발표에는 Claude Pro와 Claude Max가 명시되어 있습니다. Free, Team, Enterprise 요금제는 언급되지 않았습니다.

Claude Duet은 내 Claude 사용 한도를 쓰나요?

네. 요금제 한도를 Claude의 다른 기능과 공유합니다. 백그라운드 확인도 한도에 포함되며, 재무 모델이나 프레젠테이션 같은 큰 작업은 일반 대화보다 더 많이 씁니다.

Claude Duet은 어떤 모델을 쓰나요?

Anthropic에 따르면 Claude Duet은 Claude Opus 5.5를 중심으로 설계되었으며, Anthropic API에서 이 모델의 정가는 100만 토큰당 입력 US$4.00, 출력 US$20.00입니다.

Claude Duet이 스스로 메시지를 보내거나 결제할 수 있나요?

아니요. 메시지를 보내거나, 결제하거나, 문서에 서명하거나, 무언가를 삭제하기 전에 정확한 행동 내용을 보여 주고 승인을 기다립니다. 증권 거래와 계좌 간 자금 이체는 승인하더라도 차단됩니다.

Claude Duet은 미국 밖에서도 쓸 수 있나요?

리서치 프리뷰는 대기자 명단 방식으로 미국의 Pro 및 Max 사용자부터 시작됩니다. 발표에는 다른 지역의 일정이 나와 있지 않습니다.

컴퓨터를 꺼도 Grok Bot은 계속 작업하나요?
