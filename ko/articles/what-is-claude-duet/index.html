Claude Duet이란? Anthropic의 능동형 에이전트가 하는 일

아침 브리핑을 보내고, 연결된 계정을 살피고, 자체 클라우드 컴퓨터에서 작업을 실행하며, 전송, 결제, 서명, 삭제 전에는 확인을 요청하는 별도의 Claude 앱입니다.

Claude Duet은 Claude가 프롬프트를 기다리지 않고 먼저 대화를 시작하는 Anthropic의 앱입니다. 연결한 앱을 검토해 주의가 필요한 일을 알려 주고, 맡긴 작업을 처리하며, 앱을 닫은 뒤에도 클라우드 컴퓨터에서 작업을 이어 갑니다. Anthropic은 2026년 10월 21일 미국의 Claude Pro 및 Max 구독자를 대상으로 대기자 명단 방식의 리서치 프리뷰를 시작했습니다.

핵심 요약

  • Claude Duet은 iOS, Android, claude.ai에서 쓰는 별도 앱 형태의 능동형 에이전트입니다. 아침 브리핑을 보내고, 몇 시간마다 연결된 계정을 확인하며, 결정이 필요한 일이 생기면 메시지를 보냅니다.
  • 전문직 종사자와 소규모 사업자를 대상으로 하며, 받은편지함과 캘린더 정리, 청구서, 급여, 채용 공고, 계약서, 예측, 프레젠테이션, 대시보드 작업을 다룹니다.
  • 작업은 자체 브라우저가 있는 가상 머신에서 실행되므로 휴대폰이나 노트북을 꺼 두어도 됩니다.
  • 메시지 전송, 결제, 문서 서명, 삭제 전에는 확인을 요청합니다. 증권 거래와 계좌 간 자금 이체는 승인하더라도 차단됩니다.
  • 별도 가격은 없습니다. Claude Pro(월 US$20.00)와 Max(US$100.00 또는 US$200.00)에 포함되며, Claude의 다른 기능과 같은 사용 한도를 씁니다.

Claude Duet 개요

일반 Claude 앱은 사용자가 글을 보내면 답합니다. Claude Duet은 먼저 말을 겁니다. 매일 아침 연결된 앱 전반에서 가장 중요한 항목을 짧은 브리핑으로 보내고, 낮에는 사용자의 주의가 필요한 일이 있을 때만 메시지를 보냅니다. 사용자는 하나로 이어지는 스레드에서 텍스트나 음성으로 답하므로, 한 줄짜리 답변과 일주일짜리 프로젝트가 같은 곳에서 시작됩니다. 주제별로 별도 채널을 열 수 있으며, 채널들은 같은 메모리를 공유합니다.

Anthropic은 Claude Opus 5.5를 중심으로 이 앱을 만들었으며, 가장 필요한 능력으로 판단력을 꼽습니다. 무엇에 사용자가 필요한지, 무엇은 기다려도 되는지, 언제 행동 전에 확인해야 하는지를 가리는 능력입니다. Claude Duet은 Claude 계정의 메모리, 스킬, 연결된 앱을 그대로 가져오고 과거 대화도 검색할 수 있어 설정이 짧습니다.

Claude는 이미 Cowork에서 예약 작업을 실행할 수 있습니다. Claude Duet은 작업이나 일정을 먼저 설정하지 않아도 사용자에게 무엇을 가져올지 스스로 정합니다. 현재는 기본 Claude 앱과 분리된 별도 앱으로 제공됩니다.

활용 사례

Anthropic이 든 예시는 간단한 사무 작업부터 큰 프로젝트까지 걸쳐 있습니다. Claude Duet은 Claude Marketplace의 6,000개가 넘는 커넥터와 플러그인을 통해 다음과 같은 일을 할 수 있습니다.

큰 작업은 검토하고 수정할 수 있는 파일로 돌아옵니다. 리서치 브리프, 재무 예측이나 매출 예측, 슬라이드 자료, 대시보드, 프로토타입, 웹 앱 등입니다. 커넥터가 없는 사이트에서는 클라우드의 자체 브라우저를 사용합니다.

Anthropic 직원들은 할 일 목록을 맡기는 방식으로 쓴다고 설명합니다. 한 직원은 산책하면서 Claude Duet과 목록을 하나씩 짚어 보고, 다른 직원은 퇴근 전에 일을 넘긴 뒤 저녁 보고서로 결과를 읽습니다. Claude Duet을 만드는 팀은 사용자 인터뷰 일정을 잡고 프로토타입 작업을 하는 데 이 앱을 씁니다.

Claude Duet 작동 방식

  • 클라우드 컴퓨터. Claude Duet에는 자체 브라우저가 있는 가상 머신이 있습니다. 사용자가 짧은 메시지로 작업을 설명하면 어떤 앱을 쓰고 어떤 단계를 밟을지 Claude Duet이 정하며, 작업이 끝나거나 검토가 필요하면 알림이 옵니다.
  • 예약된 확인. 연결된 계정을 계속 살피지 않고 몇 시간마다 확인합니다. 계속 확인하면 요금제 한도가 훨씬 빨리 소진되기 때문입니다. 무엇을 얼마나 자주 보고할지 지정할 수 있습니다.
  • Tasks 탭과 Make 탭. Tasks 탭은 진행 중인 작업을 추적하고 사용자가 처리할 일을 보여 줍니다. 완성된 파일은 Make 탭에 표시됩니다. 작업을 완료로 표시할 수 있는 사람은 사용자뿐입니다.
  • 공유 컨텍스트. Claude 계정과 같은 메모리, 스킬, 커넥터를 사용하므로 두 번 설정할 필요가 없습니다.

승인과 안전

Claude Duet은 읽기, 초안 작성, 작업 준비를 스스로 합니다. 메시지를 보내거나, 결제하거나, 문서에 서명하거나, 무언가를 삭제하기 전에는 정확한 행동 내용을 보여 주고 사용자의 승인을 기다립니다. 증권 거래와 계좌 간 자금 이체 등 일부 행동은 승인하더라도 차단됩니다. Claude Duet이 접근할 수 있는 앱은 어느 것이든 연결을 해제할 수 있습니다.

Anthropic이 밝힌 그 밖의 보호 장치는 다음과 같습니다.

  • 자격 증명은 Claude Managed Agents에 쓰인 설계를 따르므로, Claude Duet은 사용자의 비밀번호나 로그인 토큰을 보지 못합니다.
  • 행동은 Claude와 Claude Code가 쓰는 것과 같은 자동 모드(auto mode) 분류기로 검사합니다.
  • 전용 분류기가 보내는 메시지를 하나하나 검사하며, 카드 번호나 정부 발급 신분증 정보의 공유를 거부합니다. 건강이나 개인 금융 정보는 사용자가 명시적으로 요청할 때만 전송됩니다.
  • 프롬프트 인젝션 방어는 Anthropic의 브라우저 사용 연구에서 나왔습니다. 레드팀과 외부 업체가 시스템을 테스트했으며, Anthropic의 공개 버그 바운티 대상에 포함됩니다.
  • Link를 통한 결제에는 가상 카드가 쓰이므로 실제 카드 번호는 공유되지 않으며, Link는 지출 건마다 승인을 요청합니다.

이용은 미국의 Pro 및 Max 구독자부터 시작되며, 초대는 여러 차례에 나뉘어 발송됩니다. Anthropic은 다른 국가나 Team, Enterprise 요금제에 대한 일정을 밝히지 않았습니다.

Claude Duet은 요금제의 사용 한도를 채팅 및 Claude Code와 공유합니다. 백그라운드 확인도 한도에 포함되며, 재무 모델이나 프레젠테이션 같은 큰 작업은 모델 턴을 더 많이 씁니다. Anthropic은 확인 1회나 작업 1건이 얼마나 쓰는지 공개하지 않으며, 9to5Mac은 백그라운드 작업 때문에 채팅만 할 때보다 한도에 더 빨리 도달할 수 있다는 Anthropic의 안내를 전했습니다.

참고로 Anthropic API에서 Claude Opus 5.5의 가격은 100만 토큰당 입력 US$4.00, 출력 US$20.00입니다. Claude Duet vs Grok Bot: 요금과 사용 한도 아티클은 이 요금으로 각 요금제의 월 요금을 토큰으로 환산합니다.

알려진 한계

Anthropic은 프리뷰의 한계로 다음을 들었습니다.

  • 스레드를 잘못 읽거나 무엇이 급한지 잘못 판단할 수 있습니다.
  • 핵심 기능이 업무 중심으로 만들어져 티켓 예매 같은 개인 용무는 상대적으로 약합니다.
  • 아직 브라우저 화면을 볼 수 없습니다.
  • 기본 Claude 앱과 분리된 별도 앱입니다.
  • 1Password에 저장된 로그인 정보로 로그인하는 기능과 시각적 Shopify 스토어프런트 편집기는 출시 예정으로 안내되어 있습니다.

자주 묻는 질문

Claude Duet은 무엇인가요?

Claude가 능동형 에이전트로 일하는 Anthropic의 앱입니다. 아침 브리핑을 보내고, 몇 시간마다 연결된 앱을 확인하며, 자체 클라우드 컴퓨터에서 작업을 처리하고, 사용자를 대신해 행동하기 전에는 확인을 요청합니다.

Claude Duet은 무료인가요? 요금은 얼마인가요?

별도 요금은 없습니다. 리서치 프리뷰 기간에는 Claude Pro(월 US$20.00)와 Claude Max에 포함되며, Claude의 다른 기능과 같은 사용 한도를 씁니다.

누가 Claude Duet을 쓸 수 있나요? 대기자 명단이 있나요?

미국의 Pro 및 Max 구독자가 대기자 명단을 통해 이용할 수 있습니다. Team과 Enterprise 요금제는 아직 지원되지 않으며, 다른 국가는 발표되지 않았습니다.

Claude Duet은 어떤 모델을 쓰나요?

Anthropic에 따르면 Claude Opus 5.5를 중심으로 설계되었습니다.

Claude Duet이 확인 없이 할 수 있는 일은 무엇인가요?

읽기, 초안 작성, 작업 준비는 확인 없이 할 수 있습니다. 메시지 전송, 결제, 서명, 삭제에는 사용자의 승인이 필요하며, 증권 거래와 계좌 간 자금 이체는 차단됩니다.

휴대폰을 꺼도 Claude Duet은 계속 작업하나요?

네. 작업은 자체 브라우저가 있는 가상 머신에서 실행되며, 작업이 끝나거나 검토가 필요하면 알림이 옵니다.

Claude Duet은 Claude 앱과 어떻게 다른가요?

Claude 앱은 프롬프트에 응답합니다. Claude Duet은 같은 메모리, 스킬, 커넥터를 사용하면서 무엇을 사용자에게 가져올지 스스로 정하고, 자체 일정에 따라 계정을 확인하며, 백그라운드에서 계속 작업합니다.
