Codex CLI

OpenAI 공식 터미널 에이전트.

Codex는 OpenAI 호환 API를 사용하므로 api.openai.com 외에도 통신할 수 있습니다. OpenAI 키를 바로 쓰거나 설정 파일에 커스텀 제공업체를 선언하세요.

공식 문서 ↗

설정 단계

  1. 1

    CLI 설치

    Node.js 18 이상이 필요합니다. 전역 명령 codex가 설치됩니다.

    bash
    npm install -g @openai/codex
  2. 2

    방법 A: OpenAI 키 사용

    OpenAI 플랫폼의 키를 설정합니다. Windows에서는 setx 후 터미널을 다시 여세요.

    bash / zsh
    export OPENAI_API_KEY="your-api-key"
    PowerShell
    setx OPENAI_API_KEY "your-api-key"
  3. 3

    방법 B: 커스텀 제공업체 추가

    설정 파일에 OpenAI 호환 엔드포인트를 선언합니다. env_key는 키가 담긴 환경 변수 이름이며, wire_api = chat은 대부분의 서드파티 엔드포인트에 적합합니다.

    ~/.codex/config.toml
    model = "your-model-name"
model_provider = "custom"

[model_providers.custom]
name = "Custom"
base_url = "https://api.example.com/v1"
env_key = "OPENAI_API_KEY"
wire_api = "chat"
  4. 4

    저장된 ChatGPT 로그인 지우기

    이전에 ChatGPT로 로그인한 경우에만 해당합니다. 이렇게 하면 Codex가 자신의 키를 사용하게 됩니다.

    bash
    codex logout
  5. 5

    코딩 시작

    프로젝트 폴더에서 실행하고 지시를 내리기 시작하세요.

    bash
    codex
팁: ChatGPT로 로그인했다면 먼저 codex logout을 실행한 뒤, 다음 실행 시 「Provide your own API key」를 선택하면 커스텀 제공업체가 사용됩니다.
먼저 더 저렴한 모델이나 제공업체를 고른 뒤, 그 키와 엔드포인트를 위 단계에 넣으세요. 가격 비교 · 제공업체 보기
