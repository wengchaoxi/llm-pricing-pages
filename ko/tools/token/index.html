이 텍스트의 모델별 비용

비용 = 토큰 ÷ 100만 × 모델 정가. 「입력으로」는 입력 가격을, 「출력으로」는 출력 가격을 사용합니다. OpenAI 이외 모델의 토큰 수는 추정치입니다.
