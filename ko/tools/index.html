도구

동일한 가격·순위 데이터를 바탕으로 하는 계산 및 비교 도구입니다.

모델 비교사용 가능

2~4개 모델을 한 표에 놓고, 값이 같은 행은 숨길 수 있습니다.

비용 계산기사용 가능

월 사용량과 캐시 적중률을 입력해 채널별 월 비용을 정렬합니다.

토큰 계산 · 토크나이저 비교사용 가능

같은 텍스트의 토큰 수와 비용을 여러 토크나이저에서 비교합니다.

구독 vs API사용 가능

내 사용량 수준에서 구독과 사용량 기반 API를 비교합니다.

AI 구독 가격사용 가능

ChatGPT, Claude, Gemini 등 소비자용 구독의 플랜 가격과 한도.

API · MCP사용 가능

가격·순위 데이터를 REST API와 MCP 서버로 제공해 에이전트가 조회할 수 있습니다.

이 도구들의 용도

계산기는 사이트의 다른 부분과 동일한 가격 및 리더보드 데이터로 동작합니다. 비용 계산기는 월간 토큰 사용량을 공식 채널과 최저가 채널 모두로 산정하며, 캐시 적중은 별도 입력으로 둡니다. 캐시된 입력은 일반 입력 요금보다 훨씬 낮게 청구되기 때문입니다.

토큰 카운터는 같은 텍스트가 모델 계열마다 다르게 토큰화되는 방식을 보여줍니다. 이는 중국어 등 CJK 텍스트에서 특히 중요하며, 최신 토크나이저일수록 글자당 필요한 토큰이 적습니다. 구독 비교는 사용량 수준에 맞춰 정액 월 요금제와 종량제 API를 견주며, 단일 손익분기점이 아니라 범위로 제시합니다.
