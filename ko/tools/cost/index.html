비용 계산기

월 사용량을 입력하고 계산할 모델을 선택하세요. 각 모델은 공식 채널과 최저가 유료 채널에서 각각 한 번씩 계산됩니다. 캐시 적중률을 별도 입력으로 둔 것은, 캐시된 입력의 단가가 일반 입력 단가보다 크게 낮기 때문입니다.

시나리오 프리셋

월 비용 = 입력×(1−적중률)×단가 + 입력×적중률×캐시 읽기 단가 + 출력×단가. 캐시 읽기 가격이 없는 채널은 입력 단가로 계산합니다. $0 채널은 제외하는데, 무료 등급은 보통 속도 제한이 있고 SLA가 없기 때문입니다. 게이트웨이 채널에는 드러나지 않은 제한이 있을 수 있으니 가용성은 직접 확인하세요.
