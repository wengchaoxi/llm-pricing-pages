Cara kerja perbandingan ini

Setiap angka di sini adalah tarif API per token yang dipublikasikan setiap penyedia, dinormalkan per satu juta token dan dinyatakan dalam dolar AS. Mata uang lain dikonversi dari angka dolar itu memakai kurs harian, jadi nilainya bersifat acuan dan bukan angka yang diterbitkan penyedia. Ketika sebuah model dihosting oleh beberapa penyedia, tabel mempertahankan kutipan masing-masing alih-alih merata-ratakannya, karena model yang sama sering berbeda dalam harga, jendela konteks, dan kemampuan dari satu host ke host lain.

Harga campuran memeringkat model dengan satu angka: harga masukan dikali 0,75 ditambah harga keluaran dikali 0,25, sesuai asumsi penggunaan masukan berbanding keluaran 3 banding 1. Kanal berbayar termurah tidak menyertakan tingkat $0, karena akses gratis biasanya memiliki batas laju dan tanpa jaminan tingkat layanan. Skor kualitas, jika ditampilkan, berasal dari Artificial Analysis; sebagian besar model tidak memiliki data kualitas independen, sehingga baris tersebut hanya menampilkan harga.

Data harga dan kemampuan diagregasi dari models.dev, serta data kualitas dan kecepatan dari Artificial Analysis. Angka bersifat indikatif dan dapat berubah, sehingga halaman resmi penyedia menjadi acuan akhir sebelum Anda memilih sebuah kanal.

Pertanyaan umum

Apa API LLM termurah pada 2026?
Berdasarkan perbandingan kami atas 1378+ model, Llama 3.2 1B Instruct dari Inference menawarkan harga gabungan terendah, sekitar $0.010 per 1J token.
Bagaimana memperkirakan biaya API LLM?
Kalikan token masukan Anda dengan harga masukan model per 1J token, lakukan hal yang sama untuk token keluaran, lalu jumlahkan. Gunakan kalkulator biaya bawaan untuk memperkirakan total bagi model dan penyedia mana pun.
LLM mana yang punya jendela konteks terbesar?
Grok 4.20 dari xai mendukung jendela konteks terbesar, hingga 2,000,000 token.
Penyedia dan model mana yang dibandingkan di sini?
Situs ini membandingkan 1378+ model lintas penyedia seperti Alibaba, Google, Mistral, Meta, OpenAI, Zhipu AI, dengan harga masukan, keluaran, dan cache per 1J token plus papan peringkat kualitas.
