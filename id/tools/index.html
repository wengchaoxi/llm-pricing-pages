Untuk apa alat-alat ini

Kalkulator berjalan pada data harga dan papan peringkat yang sama dengan bagian situs lainnya. Kalkulator biaya menghitung penggunaan token bulanan Anda pada kanal resmi maupun termurah, dengan input terpisah untuk cache-hit karena input yang di-cache ditagih jauh di bawah tarif input normal.

Penghitung token menunjukkan bagaimana teks yang sama ditokenkan secara berbeda antar keluarga model, yang paling penting untuk teks Tionghoa dan CJK lain, tempat tokenizer yang lebih baru memerlukan lebih sedikit token per karakter. Perbandingan langganan menimbang paket bulanan tetap terhadap API bayar sesuai pemakaian pada tingkat penggunaan Anda, dan dilaporkan sebagai rentang alih-alih satu titik impas.
