Sumber terbukaKompatibel OpenAIopencode

opencode

Agen terminal sumber terbuka, bekerja dengan penyedia apa pun.

opencode mengonfigurasi setiap penyedia dengan base URL alih-alih membaca OPENAI_BASE_URL. Cara tercepat adalah login interaktif; untuk kontrol penuh, edit berkas konfigurasi.

Dokumen resmi ↗

Langkah pengaturan

  1. 1

    Instal opencode

    Butuh Node.js 18 atau lebih baru. Menginstal perintah global opencode.

    bash
    npm install -g opencode-ai
  2. 2

    Opsi A: login cepat

    Jalankan perintah login, gulir ke "Other", lalu tempel base URL dan kunci API Anda.

    bash
    opencode auth login
  3. 3

    Opsi B: berkas konfigurasi

    Deklarasikan penyedia kompatibel OpenAI dengan base URL, kunci, dan model-nya. Ganti nilai dengan milik Anda.

    ~/.config/opencode/opencode.json
    {
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "custom": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.example.com/v1",
        "apiKey": "your-api-key"
      },
      "models": { "your-model-name": {} }
    }
  }
}
  4. 4

    Mulai coding

    Luncurkan di folder proyek Anda dan pilih model kustom dengan perintah /models.

    bash
    opencode
Tips: opencode tidak membaca OPENAI_BASE_URL atau OPENAI_API_KEY untuk endpoint kustom. Anda harus mendeklarasikan penyedia, baik via auth login maupun berkas konfigurasi.
Pilih dulu model atau penyedia yang lebih murah, lalu masukkan kunci dan endpoint-nya ke langkah di atas. Bandingkan harga · Jelajahi penyedia
