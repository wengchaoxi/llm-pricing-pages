Qwen3-VL Plus by alibaba is offered by 7 providers on this page. Its official list price is $0.20 per 1M input tokens and $1.60 per 1M output tokens. The lowest paid channel is AIHubMix at $0.137 / $1.37 per 1M, about 1.2× below the list price. That channel is a third-party gateway, so confirm its availability and rate limits before depending on it.

The context window is 262,144 tokens at the reference host, but hosts report different limits, from 256,000 to 262,144, so the usable window depends on the provider you pick. It supports reasoning, tool use, and structured output. Accepted input modalities are Text, Image, and Video. Providers report the capability flags inconsistently, so verify a specific feature against the host you plan to use. Its training knowledge cuts off at 2025-04.
