GPT-5 by openai is offered by 40 providers on this page. Public prices are shown for 37 of them. Its official list price is $1.25 per 1M input tokens and $10.00 per 1M output tokens. Prices vary about 2.3× across the providers that host it.

Artificial Analysis rates it 23 on the Intelligence Index, with 37.8 for coding. Against its lowest blended price of $2.93 per 1M, that is roughly 8 index points per dollar, which is the value ratio the leaderboards rank on. Median output speed is 91 tokens per second, with 74.48s to the first token.

The context window is 400,000 tokens at the reference host, but hosts report different limits, from 128,000 to 400,000, so the usable window depends on the provider you pick. It supports reasoning, tool use, and structured output. Accepted input modalities are Text, Image, and PDF. Providers report the capability flags inconsistently, so verify a specific feature against the host you plan to use. Its training knowledge cuts off at 2024-09-30.
