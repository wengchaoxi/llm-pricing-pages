Guide di configurazione CLI

Punta gli strumenti di programmazione IA da riga di comando a qualsiasi API in pochi passi. Copia, incolla, sostituisci i segnaposto con la tua chiave ed endpoint, fatto.

Le 3 cose di cui ogni strumento ha bisogno

Chiave API

Un token segreto che dimostra chi sei e viene fatturato. Tienilo privato, non fare mai commit su git.

Base URL

L’endpoint con cui lo strumento comunica. Cambialo per instradare verso un provider più economico anziché quello predefinito.

Nome del modello

Quale modello eseguire, esattamente come lo nomina il tuo provider, es. l’id del modello mostrato nella sua pagina dei prezzi.

Adatta il formato dell’endpoint allo strumento. Codex CLI, Aider, opencode e Qwen Code accettano direttamente un endpoint compatibile con OpenAI. Claude Code usa il formato Anthropic, quindi punta ANTHROPIC_BASE_URL a un endpoint compatibile con Anthropic o a un convertitore. Gemini CLI è nativo Google.
