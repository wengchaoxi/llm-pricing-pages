رسميGemini / GoogleGoogle

Gemini CLI

وكيل الطرفية الرسمي من Google.

أسرع طريق هو مفتاح API من Google AI Studio مُعيَّن كـ GEMINI_API_KEY. يمكنك أيضًا تشغيله وتسجيل الدخول بحساب Google للحصول على الطبقة المجانية.

المستندات الرسمية ↗

خطوات الإعداد

  1. 1

    ثبّت CLI

    يتطلب Node.js 20 أو أحدث. يثبّت الأمر العام gemini.

    bash
    npm install -g @google/gemini-cli
  2. 2

    احصل على مفتاح API

    أنشئ مفتاحًا مجانيًا في Google AI Studio وانسخه.

    text
    https://aistudio.google.com/apikey
  3. 3

    عيّن المفتاح

    خزّنه في متغيّر البيئة GEMINI_API_KEY. أضفه إلى ملف تعريف الصدفة لديك للحفاظ عليه بين الجلسات.

    bash / zsh
    export GEMINI_API_KEY="your-api-key"
    PowerShell
    setx GEMINI_API_KEY "your-api-key"
  4. 4

    ابدأ البرمجة

    شغّله داخل مجلد مشروعك للدردشة وقراءة الشيفرة وتعديلها.

    bash
    gemini
نصيحة: لا حاجة لمفتاح للتجربة: شغّل gemini وسجّل الدخول بحساب Google. للحصول على حدود أعلى وفوترة API، استخدم GEMINI_API_KEY.
اختر أولًا نموذجًا أو مزودًا أرخص، ثم أدخل مفتاحه ونقطة نهايته في الخطوات أعلاه. قارن الأسعار · تصفّح المزودين
