Aider

Парное программирование с ИИ с открытым кодом в вашем терминале.

Aider работает почти с любой моделью. Используйте ключи OpenAI или Anthropic напрямую либо задайте OpenAI-совместимый базовый URL, чтобы направить запросы через более дешёвого провайдера.

Официальная документация ↗

Шаги настройки

  1. 1

    Установите Aider

    Требуется Python 3.8 или новее. Устанавливает команду aider через pip.

    bash
    python -m pip install aider-chat
  2. 2

    Вариант A: используйте ключ провайдера

    Задайте ключ провайдера вашей модели, затем выберите модель через --model.

    bash / zsh
    export OPENAI_API_KEY="your-api-key"
aider --model gpt-4o
  3. 3

    Вариант B: используйте свой эндпоинт

    Задайте OPENAI_API_BASE с URL вашего провайдера и добавьте перед именем модели префикс openai/.

    bash / zsh
    export OPENAI_API_BASE="https://api.example.com/v1"
export OPENAI_API_KEY="your-api-key"
aider --model openai/your-model-name
  4. 4

    Сделайте это постоянным

    Сохраните эндпоинт, ключ и модель в файле .env в проекте, чтобы не вводить их заново.

    .env
    OPENAI_API_BASE=https://api.example.com/v1
OPENAI_API_KEY=your-api-key
AIDER_MODEL=openai/your-model-name
Совет: Для OpenAI-совместимых эндпоинтов добавьте перед моделью префикс openai/, чтобы Aider считал её моделью в стиле OpenAI, например --model openai/your-model-name.
Сначала выберите модель или провайдера подешевле, затем подставьте их ключ и эндпоинт в шаги выше. Сравнить цены · Смотреть провайдеров
