OffiziellOpenAI-kompatibelOpenAI

Codex CLI

Der offizielle Terminal-Agent von OpenAI.

Codex nutzt die OpenAI-kompatible API und kann daher mit mehr als api.openai.com sprechen. Nutze deinen OpenAI-Schlüssel direkt oder deklariere einen eigenen Anbieter in der Konfigurationsdatei.

Offizielle Doku ↗

Einrichtungsschritte

  1. 1

    CLI installieren

    Erfordert Node.js 18 oder neuer. Installiert den globalen Befehl codex.

    bash
    npm install -g @openai/codex
  2. 2

    Option A: deinen OpenAI-Schlüssel nutzen

    Setze deinen Schlüssel aus der OpenAI-Plattform. Öffne das Terminal unter Windows nach setx neu.

    bash / zsh
    export OPENAI_API_KEY="your-api-key"
    PowerShell
    setx OPENAI_API_KEY "your-api-key"
  3. 3

    Option B: einen eigenen Anbieter hinzufügen

    Deklariere einen OpenAI-kompatiblen Endpunkt in der Konfigurationsdatei. env_key benennt die Umgebungsvariable mit dem Schlüssel; wire_api = chat passt für die meisten Drittanbieter-Endpunkte.

    ~/.codex/config.toml
    model = "your-model-name"
model_provider = "custom"

[model_providers.custom]
name = "Custom"
base_url = "https://api.example.com/v1"
env_key = "OPENAI_API_KEY"
wire_api = "chat"
  4. 4

    Gespeicherte ChatGPT-Anmeldung löschen

    Nur wenn du dich zuvor mit ChatGPT angemeldet hast. Das zwingt Codex, deinen eigenen Schlüssel zu nutzen.

    bash
    codex logout
  5. 5

    Loslegen

    Führe es im Ordner deines Projekts aus und beginne, Anweisungen zu geben.

    bash
    codex
Tipp: Wenn du mit ChatGPT angemeldet warst, führe zuerst codex logout aus und wähle beim nächsten Start „Provide your own API key“, damit dein eigener Anbieter genutzt wird.
Wähle zuerst ein günstigeres Modell oder einen günstigeren Anbieter und trage dann dessen Schlüssel und Endpunkt in die Schritte oben ein. Preise vergleichen · Anbieter durchsuchen
