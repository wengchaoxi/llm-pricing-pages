API · MCP

Die normalisierten Preis-, Fähigkeits- und Ranglistendaten hinter dieser Seite werden als statisches JSON veröffentlicht, frei abrufbar und ohne API-Schlüssel. Ihr Code oder ein Agent kann sie direkt abfragen.

Endpunkte

GETmodels.jsonhttps://llmpricing.dev/api/models.json

Alle Modelle: canonical-Eintrag, offizieller + günstigster Kanalpreis, Mischpreise, Kontext, Fähigkeiten, Artificial-Analysis-Werte und 30-Tage-Nutzung.

GETproviders.jsonhttps://llmpricing.dev/api/providers.json

Alle Anbieter: Name, Stufe (Erstanbieter / Cloud / Gateway), Modellanzahl, SDK, API-Base und Docs.

GETllms.txthttps://llmpricing.dev/llms.txt

Klartext-Zusammenfassung der Seite für KI-Crawler (llms.txt-Konvention).

Wird als statische Dateien über ein CDN ausgeliefert. Die Seite setzt kein Kontingent pro Client, die allgemeinen Verkehrsgrenzen des Hosters gelten aber weiter. Bitte cachen Sie Antworten, statt sie bei jeder Anfrage neu zu laden. Die Daten werden bei jedem Build aktualisiert.

Wichtige Felder (models.json)

id, name, lab, kindCanonical-ID, Anzeigename, Labor und Modelltyp.
official / blendedOfficialPreis der eigenen API des Labors (provider, modelId, Eingabe/Ausgabe/Cache-Lesen pro 1M) und sein Mischstückpreis; null, wenn kein offizieller API-Preis erfasst ist. reference greift dann auf einen Drittanbieter-Kanal zurück, markiert durch reference.official = false.
reference / cheapestReferenz (offiziell/Liste) und günstigster kostenpflichtiger Kanal, je mit Eingabe/Ausgabe/Cache-Lesen pro 1M Tokens.
outputModalities / generationPricesDie Preise verwenden die Abrechnungseinheit des jeweiligen Anbieters. Abgerechnetes Medium und Bedingungen bestimmen die Kosten; diese Werte fließen nicht in Vergleiche von Text-Token-Preisen ein.
blendedRef / blendedMin / blendedTrustedMischstückpreis (Eingabe×0,75 + Ausgabe×0,25) für Referenz-, günstigsten und günstigsten vertrauenswürdigen Kanal (ohne Gateways).
context, outputLimit, capabilitiesKontextfenster, maximale Ausgabe und dreiwertige Fähigkeits-Flags (true/false/null).
aa (idx, coding, agentic, speed, taskCost, evals)Artificial-Analysis-Indizes für Intelligenz, Coding und Agentik, Ausgabegeschwindigkeit und Kosten pro Aufgabe. Die Free API enthält keine Einzelbewertungen je Benchmark; evals bleibt null.
usage (rank, tokens, share)OpenRouter-30-Tage-Nutzungsrang, Gesamt-Tokens und Anteil (null wenn nicht erfasst).
hostCount, spreadWie viele Anbieter das Modell hosten und die plattformübergreifende Preisspanne.
status, openWeights, releaseDate, lastUpdated, urlLebenszyklus-Status, Open-Weights-Kennzeichen, Veröffentlichungs- und Aktualisierungsdatum sowie die URL der Modellseite.

Beispiele

Die fünf günstigsten Modelle nach Mischpreis, mit curl und jq:

curl -s https://llmpricing.dev/api/models.json \
  | jq '.models
        | map(select(.blendedMin != null))
        | sort_by(.blendedMin)[:5]
        | .[] | {name, blendedMin, cheapest: .cheapest.provider}'

JavaScript (fetch):

const res = await fetch("https://llmpricing.dev/api/models.json");
const { meta, models } = await res.json();

// 5 cheapest by blended price (input x0.75 + output x0.25)
const cheapest = models
  .filter((m) => m.blendedMin != null)
  .sort((a, b) => a.blendedMin - b.blendedMin)
  .slice(0, 5);

console.log(meta.syncedAt, cheapest);

Python (requests):

import requests

data = requests.get("https://llmpricing.dev/api/models.json").json()
models = data["models"]

# highest Artificial Analysis intelligence with a public price
ranked = sorted(
    (m for m in models if m["aa"] and m["aa"]["idx"] is not None),
    key=lambda m: m["aa"]["idx"],
    reverse=True,
)
for m in ranked[:5]:
    print(m["name"], m["aa"]["idx"], m["blendedMin"])

Endpunkte senden Access-Control-Allow-Origin: *, funktionieren also auch aus dem Browser.

MCP-Server

Da die Daten sauberes JSON über HTTPS sind, kann jeder fetch-fähige MCP-Server sie einem Agenten bereitstellen. Zum Beispiel der Referenz-fetch-Server:

{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"]
    }
  }
}

Bitten Sie den Agenten dann, https://llmpricing.dev/api/models.json zu lesen. Das fetch-Tool liefert standardmäßig 5.000 Zeichen pro Aufruf und liest ab start_index weiter, und models.json ist über 1 MB groß, daher eignet es sich für gezielte Abfragen. Für Sammelfragen wie das günstigste Modell innerhalb eines Budgets lassen Sie einen Agenten mit Code-Ausführung die obigen Beispiele ausführen oder beginnen mit llms.txt, einer kleineren Textzusammenfassung.

Ein Erstanbieter-MCP-Server mit typisierten Tools (search_models, cheapest, compare) steht auf der Roadmap. Bis dahin sind die obigen JSON-Endpunkte die stabile Schnittstelle.
