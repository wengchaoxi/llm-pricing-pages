AI サブスク価格

ChatGPT、Claude、Gemini などコンシューマー向け AI サブスクリプションの料金と枠です。ユーザー単位・月額の課金で、token 単位の API とは別の軸になります。提供元ごとに料金順で並べています。

料金と上限は 2026-08-08 時点で収集した公開情報で、提供元ごとの個別確認は行っていません。プランは頻繁に変わるため、公式ページを優先してください。サブスクリプションと従量課金 API を比較するには、 サブスク vs API 計算機 →
