Claude Code

Anthropic 公式のターミナルエージェント。

Claude Code は Anthropic Messages プロトコルを使います。Anthropic のキーをそのまま使うか、2 つの環境変数で任意の Anthropic 互換エンドポイントに向けられます。

公式ドキュメント ↗

設定手順

  1. 1

    CLI をインストール

    Node.js 18 以降が必要です。グローバルコマンド claude が入ります。

    bash
    npm install -g @anthropic-ai/claude-code
  2. 2

    方法 A：Anthropic のキーを使う

    Anthropic コンソールのキーを設定します。Windows はセッションをまたいで保持します。setx の後はターミナルを開き直してください。

    bash / zsh
    export ANTHROPIC_API_KEY="your-api-key"
    PowerShell
    setx ANTHROPIC_API_KEY "your-api-key"
  3. 3

    方法 B：カスタムエンドポイントを使う

    すべてのリクエストをより安い Anthropic 互換ゲートウェイに転送します。URL とキーをプロバイダーの値に置き換えてください。

    bash / zsh
    export ANTHROPIC_BASE_URL="https://api.example.com"
export ANTHROPIC_AUTH_TOKEN="your-api-key"
  4. 4

    永続化する

    毎回 export する代わりに、エンドポイントとキーを設定ファイルに保存すれば、どのセッションでも読み込まれます。

    ~/.claude/settings.json
    {
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.example.com",
    "ANTHROPIC_AUTH_TOKEN": "your-api-key"
  }
}
  5. 5

    使い始める

    プロジェクトのフォルダーで実行します。今いる場所でファイルを読み書きします。

    bash
    claude
ヒント： api.anthropic.com 以外のベース URL は第三者ゲートウェイとして扱われます。bearer トークンを求めるゲートウェイには ANTHROPIC_AUTH_TOKEN を使ってください。
まず安いモデルやプロバイダーを選び、そのキーとエンドポイントを上の手順に入れてください。 価格を比較 · プロバイダーを見る
