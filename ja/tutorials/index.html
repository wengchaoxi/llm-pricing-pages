CLI 設定ガイド

コマンドラインの AI コーディングツールを数ステップで任意の API につなぎます。コピーして貼り付け、プレースホルダーを自分のキーとエンドポイントに置き換えるだけです。

どのツールにも必要な 3 つのもの

API キー

あなたを証明し、課金の対象となる秘密のトークンです。他人に見せず、git には絶対にコミットしないでください。

ベース URL

ツールが通信するエンドポイントです。デフォルトの代わりに、より安いプロバイダー経由にするには、ここを変えます。

モデル名

実行するモデルを、プロバイダーの表記どおりに指定します。例：料金ページに表示されるモデル ID。

エンドポイントの形式をツールに合わせてください。Codex CLI、Aider、opencode、Qwen Code は OpenAI 互換エンドポイントをそのまま使えます。Claude Code は Anthropic 形式で、ANTHROPIC_BASE_URL を Anthropic 互換エンドポイント（または変換プロキシ）に向けます。Gemini CLI は Google ネイティブです。
