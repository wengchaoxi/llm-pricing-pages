Aider

ターミナルで動くオープンソースの AI ペアプログラミング。

Aider はほぼどんなモデルでも使えます。OpenAI や Anthropic のキーをそのまま使うか、OpenAI 互換のベース URL を設定してより安いプロバイダー経由にできます。

公式ドキュメント ↗

設定手順

  1. 1

    Aider をインストール

    Python 3.8 以降が必要です。pip 経由で aider コマンドが入ります。

    bash
    python -m pip install aider-chat
  2. 2

    方法 A：プロバイダーのキーを使う

    モデルのプロバイダーのキーを設定し、--model でモデルを選びます。

    bash / zsh
    export OPENAI_API_KEY="your-api-key"
aider --model gpt-4o
  3. 3

    方法 B：カスタムエンドポイントを使う

    OPENAI_API_BASE をプロバイダーの URL に設定し、モデル名の前に openai/ を付けます。

    bash / zsh
    export OPENAI_API_BASE="https://api.example.com/v1"
export OPENAI_API_KEY="your-api-key"
aider --model openai/your-model-name
  4. 4

    永続化する

    エンドポイント、キー、モデルをプロジェクトの .env ファイルに保存すれば、毎回入力せずに済みます。

    .env
    OPENAI_API_BASE=https://api.example.com/v1
OPENAI_API_KEY=your-api-key
AIDER_MODEL=openai/your-model-name
ヒント： OpenAI 互換エンドポイントでは、モデル名の前に openai/ を付けて Aider に OpenAI 形式として扱わせます。例：--model openai/your-model-name。
