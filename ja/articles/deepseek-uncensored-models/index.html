DeepSeek Uncensored モデルとは？

510 GB の DeepSeek 重み編集版と小型の Qwen 生徒モデルを、系譜、拒否テスト、ホスティング料金、ローカル実行用ハードウェア、根拠の限界から比較します。

DeepSeek Uncensored は複数のコミュニティ派生モデルを指す名前で、いずれも DeepSeek が公開したものではありません。混同されやすい最近の 2 系統は、基盤が異なります。DeepSeek V4.1 Flash 1017 Uncensored は、DeepSeek の 552B Mixture-of-Experts モデルの重みを編集したものです。一方、DeepSeek V4 Pro Qwen3.5 9B Uncensored Heretic は、DeepSeek V4 Pro の回答とされるデータで学習し、拒否を減らすためにさらに編集された Qwen3.5-9B の生徒モデルです。

要点

  • DeepSeek は DeepSeek Uncensored という公式モデルを公開していません。各モデルについて、元のモデル、重みの作者、リビジョンを個別に確認する必要があります。
  • DeepSeek V4.1 Flash 1017 Uncensored は、DeepSeek V4.1 Flash 1017 の重み編集版です。元のチェックポイントは 1M トークンのコンテキスト、画像、動画、ツール、推論レベルに対応しますが、約 510 GB の重み一式は 4 基の H200 GPU で検証されています。
  • DeepSeek V4 Pro Qwen3.5 9B Uncensored Heretic のアーキテクチャは Qwen3.5 9B です。DeepSeek V4 Pro は、公開者が主張する教師データを提供したモデルであり、完成したモデルは DeepSeek V4 Pro の小型版ではありません。
  • 公開者によるテストでは、どちらの系統も拒否が大幅に減っています。編集前後のタスクベンチマークがあるのは V4.1 のリリースだけです。9B Heretic のリリースには拒否数と KL divergence が掲載されていますが、編集後の数学や一般知識の精度は示されていません。
  • 公式の V4.1 Flash 1017 API は、100 万トークンあたり入力 $0.15、出力 $0.60、キャッシュ済み入力 $0.003 です。ホスティングされた Uncensored エンドポイントは 2026年11月9日 時点で $0.33 / $1.32 / $0.01 でした。このサイトが 11月8日に確認した 9B のエンドポイントは、次のカタログスナップショットではなくなっていました。

1 つの名前と 2 つのモデル系譜

フルサイズの系統は DeepSeek から始まります。DeepSeek は 2026年9月10日に V4.1 Flash を公開し、10月17日に API モデルを 1017 リビジョンへ置き換えました。コミュニティの作者は、どちらのチェックポイントも重みのレベルで編集しました。この記事で確認した最初の V4.1 Uncensored リポジトリは 9月10日に作成されています。最初の 1017 リポジトリは 10月17日に登場し、10月18日に dealignai の FP8 版が続きました。

9B の系統は Qwen から始まります。Jackrong は、公開者によれば DeepSeek V4 Pro の Max Effect mode で生成された約 250,000 件の数学および STEM の例を使って、Qwen3.5-9B をファインチューニングしました。学習の説明には、教師ありファインチューニングに続いて、軽量な GSPO 強化学習を行ったとあります。その後、xtools-at がこのチェックポイントに Heretic v2 Arbitrary-Rank Ablation を適用し、10月30日に Uncensored の重みを公開しました。

曖昧な製品名を使わずに表すと、系譜は次のとおりです。

  • DeepSeek V4.1 Flash 1017 の重みを編集し、フルサイズの Uncensored モデルを作成。
  • Qwen3.5-9B を DeepSeek V4 Pro の出力とされるデータでファインチューニングし、さらに重みを編集して小型の Heretic モデルを作成。

DeepSeek は、最初の系譜では元のモデルのメーカー、2 番目の系譜では公開者が主張する教師モデルです。共通する名前が示すのは由来と拒否を減らす目的であり、共通のアーキテクチャや同等の能力を示すものではありません。

フルサイズの V4.1 Flash 1017 ビルド

派生モデルのモデルカードによると、DeepSeek V4.1 Flash 1017 は 552B パラメータのマルチモーダル Mixture-of-Experts モデルで、prefill では 8B、decoding では 16B のパラメータがアクティブになります。公式チェックポイントは 1M トークンのコンテキスト、画像と動画の入力、ツール呼び出し、選択可能な推論レベルに対応します。DeepSeek は 10月17日の更新で、9月版と比べてコーディング、エージェント、視覚のベンチマークが向上したと報告しています。たとえば、Terminal-Bench 4.0 は 31.2 から 42.3、DeepSWE v1.1 は 74.2 から 77.0 に上がりました。

dealignai の Uncensored 版は、ネイティブの FP8 と FP4 のレイアウトを維持し、システムプロンプト、アダプター、ランタイムフックを追加するのではなく、選択した重みテンソルを変更しています。リポジトリには 48 個の重みシャードがあり、保存ファイルは約 510 GB です。作者は 4 基の H200 GPU で検証しました。モデルカードには、そのマシンの総 VRAM が約 564 GB とあり、モデルの Engram メモリの一部をホスト RAM に移せることも記載されています。したがって、元のモデルの 1M コンテキストはモデル自体の上限であり、すべてのホスティング先がコンテキスト全体を提供するという保証ではありません。

mrfakename による別の 1017 ビルドは、チャットモードと thinking モードで拒否の方向が異なったため、rank-2 の拒否部分空間を使っています。このリリースでは、100 件のチャットプロンプトで 4 件、100 件の thinking プロンプトで 9 件の拒否が報告されました。dealignai の結果との差は重要です。「Uncensored」は複数の編集に共通する目標であり、互換性のある単一のチェックポイントを指す名前ではありません。

小型の Qwen3.5 9B Heretic ビルド

小型モデルは、Qwen3.5 の 32 層ハイブリッドテキストアーキテクチャとビジョンエンコーダーを維持しています。設定では、最大位置長 262,144 トークン、画像と動画のトークン、thinking 出力、ツール呼び出しテンプレートが宣言されています。BF16 リポジトリのファイルは約 19.3 GB で、Apache 2.0 licence を採用しています。DeepSeek V4 Pro という名前は、Jackrong が説明する学習データの系譜を示しています。

元の蒸留チェックポイントについて、公開者は GSM8K で 94.50%、MMLU-Pro の数学、物理、化学の各サブセットから 500 問ずつ抽出した比較で平均 90.53% と報告しています。同じカードでは、この 3 サブセットの比較で、未変更の Qwen3.5-9B は 89.60% とされています。これらの数値は異なる量子化ビルドとバックエンドで測定されたもので、xtools-at が Heretic を適用する前のチェックポイントの結果です。

ローカル用の変換を見ると、サイズの違いが具体的にわかります。Q4_K_M のあるリリースは、5.24 GiB のテキストモデルと、別ファイルの 876 MiB ビジョンプロジェクターで構成されています。NVFP4 変換版は、16 GB の RTX Pro 2000 Blackwell 上でテキスト重みを 9.65 GiB で読み込み、サーバーコンテキストを 16K に設定した公開者の単一リクエストテストで、約 29 トークン/秒を生成しました。このテストでは、ネイティブ量子化されたビジョン機能の提供は検証されていません。これらの測定値は、そのファイルと設定についての値であり、すべての変換版に共通するハードウェア要件ではありません。

拒否テストからわかること

公開されたテストは、共通のプロンプトセットや評価者を使っていません。そのため、拒否数を使ってモデル同士を順位付けすることはできません。

リリース公開者による拒否結果編集後の能力確認主な限界
dealignai V4.1 Flash 1017 Uncensored最大推論レベルで 320/320 が compliant と分類1,140 問の MMLU サンプルで 83.77%、比較対象は 87.63%、−3.86 パーセントポイント元のモデルには公式 API、編集後のモデルにはセルフホストのエンジンを使用
mrfakename V4.1 Flash 1017 Abliteratedチャットで 4/100 件、thinking で 9/100 件の拒否無害なプロンプトに対する最初のトークンの分布で KL divergence 0.067一部の回答が完了する前に推論過程を評価
xtools-at Qwen3.5 9B Heretic元のチェックポイントは 100/100 件の拒否、Heretic は 3/100 件KL divergence 0.0422編集後のタスク精度ベンチマークは未公開

KL divergence は、選択した無害なプロンプトに対し、編集後のモデルの出力分布がどの程度変化したかを測るものです。値が小さいことは、このテストにおける分布の変化についての限定的な主張を裏づけます。GSM8K、MMLU-Pro、画像、ツール呼び出しの精度が維持されたことを示すものではありません。そのため、9B モデルが継承した数学のスコアは元のチェックポイントについての参考情報であり、Uncensored 版を測定したスコアではありません。

V4.1 の結果は、実際のトレードオフも示しています。dealignai の初期の 9月ビルドでは、MMLU が 86.96% から 82.74% に下がり、低下の大部分は道徳的な状況と専門的な法律に関する問題に集中していました。1017 のテストでは、サンプルセット上で低下幅が小さくなっています。拒否を取り除いても、多くの一般的なタスクでは元のモデルに近い性能を保てますが、ためらいや拒否を評価するベンチマークの回答は変わることがあります。

API 料金とローカルサイズ

料金は 2026年11月9日 に確認した、100 万トークンあたりの USD 価格です。「過去に掲載」とは、保存済みのカタログスナップショットにそのエンドポイントがあり、次のスナップショットにはなかったことを意味します。すべてのプロバイダーがその重みの提供をやめたことを証明するものではありません。

確認時点の料金では、ホスティングされたフルサイズの Uncensored ビルドは、キャッシュされていない入力と出力のどちらも公式 1017 ベースの 2.2 倍でした。小型の 9B モデルは出力トークン単価が安かったものの、別のモデルであり、1 回のスナップショットの後に掲載がなくなっています。同じ能力を買えるかのように 2 つの料金を比較すると、Qwen アーキテクチャ、蒸留の工程、はるかに小規模なデプロイ、編集後のタスク評価がないことを無視することになります。

以前からある R1 の掲載モデルも、名前に注意が必要なことを示しています。片方は Llama 3.3 70B、もう片方は Qwen2.5 32B から派生しています。どちらも重みを編集する前に、DeepSeek R1 の回答から蒸留されました。現在ホスティング先が提供するコンテキスト上限は、元のチェックポイントの公開上限より小さく、どちらのコミュニティリポジトリにも編集前後のタスクベンチマークはありません。

選択肢の違い

フルサイズの V4.1 Flash 1017 ビルドは、最近の DeepSeek チェックポイントのアーキテクチャ、マルチモーダル入力、エージェント機能を維持しています。この規模では、ホスティングされた推論かデータセンター向けハードウェアを使うのが現実的です。また、能力低下について、公開者が最も明確な編集前後の根拠を示しています。トークン単価は DeepSeek の公式エンドポイントより高くなります。

9B Heretic ビルドの用途は異なります。DeepSeek 由来の特定の STEM ファインチューニングを含む、小型のマルチモーダル Qwen モデルを使ったローカル実験向けです。一般消費者向け GPU で動く変換版もありますが、量子化、コンテキストの割り当て、画像対応、MTP の扱いはそれぞれ異なります。このリリースには拒否テストがありますが、Heretic 編集後の数学、知識、ツールのベンチマークは再実施されていません。

R1 Distill の派生モデルは、カタログに掲載された 1 つのホストから引き続き利用でき、以前のテキスト専用チェックポイントを基にしています。モデルカードでは、abliteration は概念実証とされています。利用できるという事実だけでは、未編集の重みと測定結果を比較した場合ほどの根拠にはなりません。

注意点

  • リポジトリ ID 全体を確認してください。「DeepSeek V4 Pro 9B」は Qwen の生徒モデルを指すことがあり、「V4.1 Flash 1017 Uncensored」は個別に編集された複数の DeepSeek チェックポイントを指すことがあります。
  • モデルの上限とプロバイダーの上限を分けて考えてください。9B の重みでは 262K コンテキストが宣言されていますが、以前のホスティング先が提供していたのは 32K でした。V4.1 の元のモデルは 1M に対応しますが、ホスト側が小さい上限を設定することがあります。
  • 公開者のベンチマークは、公開者による結果として扱ってください。公開されているテストは参考になりますが、すべての Uncensored リリースを同一の手順で比較した独立評価はありません。
  • 拒否を減らすと、保護層が 1 つなくなります。入力または出力のモデレーションが必要なデプロイでは、別途追加してテストする必要があります。
  • 量子化されたファイルを正確に確認してください。名前に同じモデル名が含まれていても、BF16、NVFP4、GGUF の各リリースで、ファイルサイズ、メモリ使用量、画像対応、speculative decoding が異なる場合があります。

よくある質問

DeepSeek Uncensored は DeepSeek の公式モデルですか？

いいえ。DeepSeek が公開しているのは、元の V4.1 Flash と V4 Pro です。ここで取り上げた Uncensored 版は、コミュニティの作者が公開済みの重みやコミュニティのファインチューニングを編集して作成しました。

DeepSeek V4 Pro Qwen3.5 9B は DeepSeek V4 Pro の小型版ですか？

アーキテクチャは Qwen3.5-9B です。公開者によると、ファインチューニングに使った数学と STEM の回答を DeepSeek V4 Pro が生成しました。そのため、DeepSeek という名前は教師モデルの系譜を表しており、アーキテクチャを示すものではありません。

一般消費者向け GPU で動かせる DeepSeek Uncensored モデルはどれですか？

Qwen3.5 9B Heretic の系統には、一般消費者向けサイズの変換版があります。検証済みの NVFP4 テキストデプロイは、16 GB GPU 上で 9.65 GiB を使用しました。Q4_K_M のテキストファイルは約 5.24 GiB です。フルサイズの V4.1 Flash チェックポイントは約 510 GB で、4 基の H200 GPU で検証されています。

Uncensored なら、どんなリクエストにも答えますか？

それを保証する共通仕様はありません。公開された結果では、V4.1 のあるテストで拒否と分類された回答がゼロだった一方、別のテストでは 100 件あたり 3、4、9 件の拒否がありました。結果はチェックポイント、プロンプトセット、推論モード、評価者によって異なります。

9B Heretic モデルは元の数学スコアを維持していますか？

公開された資料では実証されていません。GSM8K の 94.50% と、MMLU-Pro の 3 サブセットにおける 90.53% は、Jackrong の元のチェックポイントの数値です。xtools-at は編集後の拒否数と KL divergence を報告していますが、編集後のタスクベンチマークは掲載していません。

DeepSeek Uncensored の料金はいくらですか？

確認した V4.1 Flash 1017 Uncensored エンドポイントは、100 万トークンあたり入力 $0.33、出力 $1.32 でした。このサイトが短期間確認した Qwen3.5 9B のエンドポイントは、11月8日時点で入力、出力とも $0.28 でしたが、次のスナップショットではなくなっていました。料金とモデルのリビジョンは合わせて確認する必要があります。

どのライセンスが適用されますか？

DeepSeek V4.1 Flash 1017 と、ここで取り上げた Uncensored FP8 派生モデルは MIT を使用しています。Qwen3.5 9B、Jackrong のファインチューニング、xtools-at の Heretic リポジトリは Apache 2.0 を使用しています。変換されたファイルには、元のライセンスが求める表示を残す必要があります。
