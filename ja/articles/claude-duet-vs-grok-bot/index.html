Claude Duet と Grok Bot：それぞれの料金と利用上限の仕組み

各エージェントが含まれるプラン、現在利用できる人、利用上限の仕組み、プラン料金を API の定価で換算した場合の利用量をまとめています。

Claude Duet（Anthropic、2026年10月21日からリサーチプレビュー）と Grok Bot（xAI、2026年8月から初期ベータ）は、どちらも専用のクラウド上のコンピューターで動作し、アプリを閉じた後も作業を続け、操作の前に承認を求めます。単体の製品としては販売されておらず、コンシューマー向けサブスクリプションに含まれています。そのため、料金はそのエージェントを利用できるプランの料金になります。

要点

  • Claude Duet に単体の料金はありません。Claude Pro（月額 $20.00）と Claude Max（$100.00 または $200.00）に含まれ、ウェイトリスト制で、まず米国のアカウントに提供されます。
  • Grok Bot は Grok Premium（月額 $30.00）、Super（$100.00）、Ultra（$200.00）と、対象となる Teams および Enterprise プランに含まれます。Super と Ultra では、週ごとの Grok Bot の利用枠が Premium の 3.5 倍と 12 倍になります。
  • どちらのベンダーも利用上限の絶対値を公開していません。Claude Duet は Claude のほかの機能と同じ上限を使い、Grok Bot の利用枠は基準となるプランに対する倍率でのみ示されています。
  • 最も安い利用開始価格：Claude Duet は Claude Pro の月額 $20.00、Grok Bot は Grok Premium の月額 $30.00 です。

Claude Duet：料金と利用上限

Anthropic は Claude Duet を、専門職や小規模事業者向けの能動型エージェントと説明しています。毎朝短いブリーフィングを送り、数時間おきに連携したアカウントを確認し、割り当てられたタスクを仮想マシン上で進めるため、スマートフォンやノート PC を起動したままにしておく必要はありません。リサーチプレビューの期間中は追加料金なしで Pro と Max に含まれ、Claude のほかの機能と同じ利用上限を使います。

Claude Duet が含まれるプラン

プラン月額料金出典
Claude Pro$20.00/月、年払いは $16.67/月公式ページ ↗
Claude Max 5x$100.00/月公式ページ ↗
Claude Max 20x$200.00/月公式ページ ↗

Anthropic によると、バックグラウンドのチェックはプランの上限に算入されます。Claude Duet が常時ではなく数時間おきに確認するのはそのためです。財務モデルやスライド資料のような大きな作業はモデルのターン数が増え、通常の会話より多くの利用枠を使います。Claude Duet のタスク数やトークン数の絶対値は公開されていないため、実際の上限はバックグラウンドの作業をどれだけ任せるかによって変わります。

利用はウェイトリスト制で、米国の Pro・Max ユーザーから始まります。発表が対象としているのはこれらのアカウントだけで、ほかのプランや地域での提供時期は示されていません。

Claude Duet は Claude Opus 5.5 を中心に設計されています。Anthropic の API では、Opus 5.5 の価格は 100 万トークンあたり入力 $4.00、出力 $20.00、キャッシュ読み取り $0.20 です。これは Claude Opus 5 の入力 $5.00、出力 $25.00 より低い価格です。

Grok Bot：料金と利用上限

xAI は Grok Bot を、ユーザーのツールにサインインし、ユーザーと同じように操作して、完成した成果物を返す AI チームメイトと説明しています。Bot はアカウント内のすべての Bot が共有するクラウド上のコンピューターで動作し、複数の Bot が並行して作業できます。一度実演したワークフローは、ルーティンとして保存してスケジュールに沿って実行できます。

Grok Bot が含まれるプラン

Grok Super$100.00/月Premium の 3.5 倍ピーク時のモデルへの優先アクセス公式ページ ↗
Grok Ultra$200.00/月Premium の 12 倍すべての製品とモデルを最も早く利用できる公式ページ ↗

xAI は利用量を絶対値ではなく倍率で示しています。Grok Bot ページでは、Super が Premium の 3.5 倍、Ultra が 12 倍です。一方、料金ページは Plus を基準にしており、Premium が Plus の 4 倍、Super が 15 倍です。これを換算すると、Premium と Super の差は 3.75 倍になります。2 つのページは基準が異なり、Ultra は Grok Bot ページにしか載っていません。

Grok Bot は対象となる Teams と Enterprise プランにも含まれます。料金ページには月額 $8.00 の Plus も載っていますが、Grok Bot の記載があるのは Premium 以上のプランです。

Grok Bot ページには使用モデルの記載がなく、料金ページには Premium に最新の Grok モデルが含まれるとあります。当サイトのカタログで最新の Grok モデルは Grok 4.7 で、2026年9月21日リリース、xAI の API での価格は 100 万トークンあたり入力 $2.00、出力 $6.00 です。

プラン料金を API の定価で換算すると

プラン料金は、モデルの API 価格でトークン数に換算できます。どちらのベンダーもプランに含まれるトークン数を公開していないため、これは単位の換算であり、利用枠ではありません。表では当サイト全体で使っている合算単価（入力 75%、出力 25% の加重平均）を使い、キャッシュ割引は含めていません。同じコンテキストを繰り返し読み込むエージェントのループでは、キャッシュ割引によってコストが下がります。

バックグラウンド作業で計算が変わる理由

チャットのプランは、ユーザーが入力したときに消費されます。これらのエージェントは、ユーザーが入力していないときにも消費します。Claude Duet は数時間おきに連携アカウントを確認しており、Anthropic によると、常時確認するとプランの上限をはるかに早く使い切ります。Grok Bot はルーティンをスケジュールに沿って実行し、複数の Bot を同時に動かせます。xAI はこれを 24 時間 365 日の稼働と説明しています。

利用枠をどれだけ使うかは、有効になっている連携アプリやスケジュール済みのルーティンの数と、各タスクの大きさによって変わります。Anthropic は財務モデルやスライド資料を重い作業として挙げています。xAI のプランの違いは主に週ごとの Grok Bot 利用枠なので、上位プランに移る実際の理由は、稼働させておく Bot の数になります。

上位プランに支払う前に、エージェントがバックグラウンドで何をしているかを確認してください。有効なルーティンと連携中のアカウントを洗い出します。Claude Duet では、何をどのくらいの頻度で報告するかを設定できます。

その他の常駐型エージェント

ほかに 3 つのコンシューマー向けエージェントが、ユーザーが離れた後も作業を続けるクラウド上のコンピューターという同じ設計を採っています。3 つとも Claude Duet より前に発表されました。常駐型 AI エージェントの解説では 5 製品すべてを比較しています。

Meta MuseMeta2026年9月8日週ごとの上限付きで無料。ほかに月額 $20.00 の Power と月額 $100.00 の Maximum。米国で iOS、Android、muse.ai、WhatsApp に対応

どちらが合うか

  • 米国で Claude Pro または Max を利用していて、Claude のメモリ、スキル、コネクタと連動するアシスタントがほしい場合：Claude Duet はプレビュー期間中は追加料金がかからず、現在の上限の範囲内で動作します。
  • 複数のエージェントを並行して動かしたい、実演でルーティンを教えたい、またはデスクトップアプリが必要な場合：Grok Bot（月額 $30.00 から）。
  • 価格だけで比べる場合：$20.00 の Claude Pro のほうが利用開始価格は低いものの、Claude Duet はウェイトリスト制で米国から先に提供されます。$30.00 の Grok Premium には Grok Bot が含まれ、xAI のページではプランに付いてダウンロードできると案内されています。

よくある質問

Claude Duet は無料ですか？

個別の料金は示されていません。リサーチプレビューの期間中、Claude Duet は Claude Pro（月額 $20.00）と Claude Max（$100.00 または $200.00）に含まれ、Claude のほかの機能と同じ利用上限を使います。利用はウェイトリスト制で、まず米国のユーザーに提供されます。

Grok Bot の料金はいくらですか？

Grok Bot は月額 $30.00 の Grok Premium、$100.00 の Super、$200.00 の Ultra に含まれます。xAI の Grok Bot ページによると、Super と Ultra では週ごとの利用量が Premium の 3.5 倍と 12 倍になります。対象となる Teams と Enterprise プランにも含まれます。

Claude Duet が含まれるのはどの Claude プランですか？

Anthropic の発表で挙げられているのは Claude Pro と Claude Max です。Free、Team、Enterprise プランには触れていません。

Claude Duet は Claude の利用上限を消費しますか？

はい。プランの上限を Claude のほかの機能と共有します。バックグラウンドのチェックも上限に算入され、財務モデルやスライド資料のような大きなタスクは通常の会話より多く消費します。

Claude Duet はどのモデルを使っていますか？

Anthropic によると、Claude Duet は Claude Opus 5.5 を中心に設計されています。Anthropic の API での価格は 100 万トークンあたり入力 $4.00、出力 $20.00 です。

Claude Duet は自分の判断でメッセージを送ったり支払ったりできますか？

いいえ。メッセージの送信、支払い、文書への署名、何かの削除の前には、実行する操作をそのまま示して承認を待ちます。証券の売買と口座間の送金は、承認があってもブロックされます。

Claude Duet は米国以外で使えますか？

リサーチプレビューは、米国の Pro・Max ユーザーからウェイトリスト制で始まります。発表では、ほかの地域での提供時期は示されていません。

コンピューターの電源を切っても Grok Bot は作業を続けますか？

xAI は、Bot が専用のクラウド上のコンピューターで動作し、24 時間 365 日作業すると説明しています。そのため、ノート PC を起動したままにしておく必要はありません。
