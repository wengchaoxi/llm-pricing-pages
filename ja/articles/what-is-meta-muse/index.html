Meta Muse とは？Meta のパーソナル AI エージェントを解説

人にメッセージを送るように指示できるエージェントです。目標に向けて計画を立て、ブラウザを開き、フォームに入力し、交渉し、1 回限りのカード番号で支払います。仮想マシンの外に出る操作は、別の Sentinel エージェントが承認します。

Muse（Meta Muse とも呼ばれます）は、Meta が 2026年9月8日に発表したパーソナル AI エージェントです。Muse アプリか WhatsApp でやってほしいことを伝えると、Muse が実際に操作します。ブラウザを開く、フォームに入力する、メールを送る、旅行を予約する、あなたの代わりに交渉する、といったことができます。時間のかかるタスクはアプリを閉じた後も続き、状況が変わったときや承認が必要なとき（メールの送信前や購入の前など）に Muse から連絡が来ます。

要点

  • Muse は日常の目標や用事のための一般消費者向けエージェントで、メール、旅行、フォーム、各種料金、買い物、計画を扱います。Meta の Muse Spark モデルで動作します。
  • Muse Secure VM 上で動作します。これはユーザーごとに用意されるクラウド上の専用マシンで、エージェントとあなたのデータを保持します。インターネットに出るものはすべて、別の Sentinel エージェントの承認が必要です。
  • あなたにとって大事なことを記憶し、頼まれなくても提案をします。特定の情報を忘れるよう指示することもできます。
  • Muse は週ごとの利用上限付きで無料です。Power（月額 $20.00）は利用枠を週 5 億 Muse トークンに、Maximum（月額 $100.00）は週 30 億 Muse トークンに引き上げます。
  • 米国で iOS、Android、muse.ai、WhatsApp から利用できます。Meta によると、AI グラスへの対応も予定されています。

Meta Muse とは

Meta は Muse を、目標の達成を手伝い、アイデアを提案する、安全でプライベートなパーソナルエージェントと説明しています。やり取りは人にメッセージを送るのと同じ形式で、そのため専用アプリだけでなく WhatsApp の中でも使えます。Meta によると、使い始めるのに技術的な知識は要りません。

メールの送信や旅行の予約のような単発のタスクも、もっと大きな目標も任せられます。目標の場合、Muse はあなた向けの計画づくりを手伝い、時間とリソースを調整したうえで、自分で作業を進めます。Meta が挙げる例には、車をより高く売る、請求額を下げる、ほかの予定の変化に合わせてトレーニング計画を調整する、などがあります。

Muse の名前を持つ Meta 製品は複数あります。Muse は一般消費者向けのエージェントアプリです。Muse Spark はその背後にあるクローズドなモデルで、開発者は Meta の API から呼び出せます。報道ではそのバージョンは 1.3 とされており、料金は 100 万トークンあたり入力 $1.25、出力 $4.25 です。Muse Glimmer はオープンウェイトのモデル、Muse Code はターミナルで動くコーディングエージェントです。

主な用途

用途Muse がすること
メールとメッセージあなたの承認を得てから、メールや招待状を作成して送信
旅行と予約旅行やレストランの席を予約
フォームと事務手続きブラウザを開き、複数ステップのフォームを入力
各種料金見積もりを比較し、あなたの代わりに交渉
買い物レシピを買い物リストにし、Link by Stripe で決済
計画目標に向けた計画を立て、最新の状態に保つ

Meta が挙げる記憶の活用例では、Muse は Instagram に保存したレシピのリール動画を買い物リストにし、ディナーパーティーのメニューを提案し、友人の食事制限を覚えたうえで招待状を送れます。

2026年9月17日にリリースされた Muse for Mac では、エージェントがファイル、メール、メッセージ、カレンダー、メモなどのローカルアプリを扱えるようになり、ダウンロードフォルダの整理やローカルファイルを使ったフォーム入力といった作業ができます。ローカルへのアクセスはオプトイン方式で、削除や送信にはあなたの承認が必要です。

セキュリティとプライバシー

Meta の設計では、エージェントとあなたのデータを 1 台の隔離されたマシンに置き、ネットワークの手前に 2 つ目のエージェントを配置しています。

  • Muse Secure VM：各ユーザーの Muse はクラウド上の専用コンピューターで動作し、他のエージェントはそこにアクセスできません。データと、連携したサービスの認証情報はそこに保存されます。
  • Sentinel：同じマシン上にある別のエージェントで、システムレベルで Muse から切り離されています。Muse の操作は Sentinel が承認しない限りインターネットに届かず、必要に応じて Sentinel があなたに確認します。
  • 認証情報：Muse はあなたのパスワードや支払い方法を見ることができません。共有した認証情報は安全なストレージに保管され、Muse は中身を読まずにそれを使えます。
  • 承認と操作履歴：メールの送信や購入などの重要な操作の前に、Muse はあなたに確認します。実行済みの操作と予定している操作の記録もすべて表示します。
  • アクセス管理：Muse をどのアプリに接続するか、どこまでアクセスを許すか（メールなら読み取りのみ、または読み取りと送信など）はあなたが選びます。サービスの接続はいつでも解除できます。
  • データの利用：Muse は会話や仮想マシン内のデータを Meta の広告システムと共有しません。また、やり取りを Meta のモデルの学習に使わせないようオプトアウトできます。

支払いは Link by Stripe を通じて行われ、1 回限りのカード番号が発行されます。Meta によると、Muse は Link の購入保護の対象となる最初の AI エージェントです。Shop Pay と 1Password への対応は近日予定とされています。Meta はさらに、マシン全体をあなただけが持つ鍵で暗号化する Muse Confidential VM も計画していますが、まだ提供されていません。

Meta Muse の料金とプラン

プラン月額料金週あたりの利用枠
Free$01 億 Muse トークン（Mark Zuckerberg のローンチ時の投稿による）
Power$20.005 億 Muse トークン
Maximum$100.0030 億 Muse トークン

Meta のヘルプセンターによると、週あたりの利用枠は上位のプランにアップグレードするほど増えます。無料の上限に達した場合は、アップグレードするか、枠が回復するまで待つことになります。サブスクリプションの加入者は 18 歳以上で、Meta アカウントでログインし、Muse が提供されている国にいる必要があります。Muse とそのサブスクリプションは限定テスト中で、米国で提供されています。

Muse トークンは Meta 独自の利用単位です。Muse Spark API のトークンとの関係を Meta は示していないため、当サイトではこの利用枠を API の費用に換算していません。GoSearch が引用したテストでは、無料プランでの負荷の高いセッション 1 回で、週の利用枠の約 9% を消費しました。

まだ足りない点

  • Muse は米国のみで、Meta は他の国での提供時期を示していません。
  • 現在の保護は Meta が運用しています。Meta 自身もアクセスできなくなる Confidential VM は発表済みですが、まだリリースされていません。
  • 報道機関のテスターは、Muse が何年も前に閉店したレストランを勧めたと報告しています。また Business Insider は、Muse が Instagram 動画の最初のフレームしか見られないことを確認しました。
  • 各プランで週に何件のタスクを実行できるか、1 件のタスクをどれだけの時間実行できるかを、Meta は公開していません。

よくある質問

Meta Muse とは何ですか？

Muse アプリや WhatsApp でメッセージを送って使う、Meta のパーソナル AI エージェントです。専用のクラウド上のコンピューターで、メールの送信、旅行の予約、フォームの入力、買い物などをあなたの代わりに行います。

Meta Muse は無料ですか？

はい、週ごとの利用上限付きで無料です。月額 $20.00 の Power と月額 $100.00 の Maximum では、週あたりの利用枠がそれぞれ 5 億、30 億 Muse トークンに増えます。

Muse はどのモデルで動いていますか？

Meta によると、Muse は同社で最も高性能なモデルである Muse Spark で動作します。報道では Muse Spark 1.3 とされています。

Meta Muse はどこで使えますか？

米国で、iOS、Android、muse.ai、WhatsApp、および Mac アプリから使えます。Meta によると、AI グラスへの対応も予定されています。

Muse は確認なしにお金を使うことがありますか？

いいえ。購入の前にあなたに確認し、Link by Stripe 経由で 1 回限りのカード番号を使って支払います。保存済みの支払い方法を Muse が見ることはできません。

Muse の Sentinel とは何ですか？

同じクラウドマシン上で動く別のエージェントで、Muse がインターネットに送るものはすべて Sentinel の承認が必要です。必要に応じて、Sentinel があなたに許可を求めます。

Meta は Muse のデータを広告に使いますか？

Meta によると、Muse は会話や仮想マシン内のデータを広告システムと共有しません。また、やり取りをモデルの学習に使わせないようオプトアウトすることもできます。
