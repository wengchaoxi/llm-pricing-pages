Claude Duet とは？Anthropic の能動型エージェントでできること

朝のブリーフィングを送り、連携したアカウントを確認し、専用のクラウド上のコンピューターでタスクを実行し、送信、支払い、署名、削除の前に確認を求める、独立した Claude のアプリです。

Claude Duet は、Claude がプロンプトを待たずに自分から会話を始める Anthropic のアプリです。連携したアプリを確認して対応が必要なことを知らせ、任されたタスクを引き受け、アプリを閉じた後もクラウド上のコンピューターで作業を続けます。Anthropic は 2026年10月21日に、米国の Claude Pro・Max 加入者を対象に、ウェイトリスト制のリサーチプレビューとして公開しました。

要点

  • Claude Duet は、iOS、Android、claude.ai で使える専用アプリの能動型エージェントです。朝のブリーフィングを送り、数時間おきに連携アカウントを確認し、判断が必要なことがあるとメッセージで知らせます。
  • 対象は専門職や小規模事業者で、受信トレイとカレンダーの整理、請求書、給与計算、求人票、契約書、予測、スライド資料、ダッシュボードといった作業を想定しています。
  • タスクは専用ブラウザを備えた仮想マシン上で実行されるため、スマートフォンやノート PC の電源は切っていてもかまいません。
  • メッセージの送信、支払い、文書への署名、何かを削除する前には確認を求めます。証券の売買と口座間の送金は、承認があってもブロックされます。
  • 個別の料金はありません。Claude Pro（月額 $20.00）と Max（$100.00 または $200.00）に含まれ、Claude のほかの機能と同じ利用上限を使います。

Claude Duet とは

通常の Claude アプリは、ユーザーが書き込むと応答します。Claude Duet は自分から先に書きます。毎朝、連携したアプリ全体から重要な項目をまとめた短いブリーフィングを送り、日中は対応が必要なことがあるときだけメッセージを送ります。返信はテキストか音声で、継続する 1 つのスレッドの中で行います。そのため、1 行の返答も 1 週間かかるプロジェクトも同じ場所から始まります。トピックごとに別のチャンネルを開くこともでき、チャンネル同士で同じメモリを共有します。

Anthropic は Claude Opus 5.5 を中心にこのアプリを構築しており、必要な能力として判断力を挙げています。ユーザーの対応が必要なこと、後回しにできること、実行前に確認すべきタイミングを見極める力です。Claude Duet は Claude アカウントのメモリ、スキル、連携アプリを引き継ぎ、過去の会話も検索できるため、セットアップは短時間で済みます。

Claude はすでに Cowork でスケジュール済みのタスクを実行できます。Claude Duet は、タスクやスケジュールを先に設定しなくても、何をユーザーに知らせるかを自分で判断します。現時点では、メインの Claude アプリとは別の専用アプリとして提供されています。

用途

Anthropic が挙げる例は、細かな事務作業から大きめのプロジェクトまであります。Claude Marketplace にある 6,000 を超えるコネクタとプラグインを通じて、Claude Duet は次のような作業ができます。

作業Anthropic の例
メッセージ見落とした Gmail と Slack のメッセージを見つけ、返信を下書きする
請求QuickBooks や Stripe で未払いの請求書を確認し、催促の連絡を下書きする
給与計算勤務時間、賞与、経費精算を入力したうえで、Gusto で給与計算を準備・実行する
採用求人票を下書きし、ユーザーが編集・承認した後に LinkedIn に掲載する
契約契約書を作成し、Docusign で署名に回す
営業HubSpot の連絡先と商談の履歴から、フォローアップのメールを下書きする
マーケティング製品の発表を Canva でソーシャルキャンペーンにする
オンラインストアShopify ストアを立ち上げ、デザインし、運営する
購入Stripe の Link ウォレットや Shop Pay で事業用の買い物をする

大きな作業は、確認・編集できるファイルとして返ってきます。たとえば調査の概要資料、財務や売上の予測、スライド資料、ダッシュボード、プロトタイプ、ウェブアプリです。コネクタのないサイトでは、クラウド上の専用ブラウザを使います。

Anthropic の社員は、ToDo リストを渡す使い方を紹介しています。ある社員は散歩しながら自分のリストを Claude Duet と口頭で確認し、別の社員は退勤前に作業を任せて、結果を夕方のレポートで読んでいます。Claude Duet を開発するチームは、ユーザーインタビューの日程調整やプロトタイプの作業に使っています。

Claude Duet の仕組み

  • クラウド上のコンピューター：Claude Duet は専用ブラウザを備えた仮想マシンを持っています。短いメッセージでタスクを伝えると、どのアプリを使い、どの手順を踏むかを自分で決めます。作業が終わったときや確認が必要なときには通知が届きます。
  • 定期チェック：連携アカウントは常時ではなく数時間おきに確認します。常時確認するとプランの上限をはるかに早く使い切るためです。何をどのくらいの頻度で報告するかは指定できます。
  • Tasks タブと Make タブ：Tasks タブは進行中の作業を管理し、ユーザーの対応が必要なものを表示します。完成したファイルは Make タブに表示されます。タスクを完了にできるのはユーザーだけです。
  • 共有されるコンテキスト：Claude アカウントと同じメモリ、スキル、コネクタを使うため、二重に設定する必要はありません。

承認と安全性

Claude Duet は、読む、下書きする、作業を準備するといったことは自分で進めます。メッセージの送信、支払い、文書への署名、何かの削除の前には、実行する操作をそのまま示して承認を待ちます。証券の売買や口座間の送金など、承認があってもブロックされる操作もあります。Claude Duet がアクセスできるアプリは、どれでも接続を解除できます。

Anthropic が挙げるそのほかの安全策は次のとおりです。

  • 認証情報は Claude Managed Agents と同じ設計に従っているため、Claude Duet がパスワードやサインイン用のトークンを目にすることはありません。
  • 操作は、Claude と Claude Code が使っているのと同じ auto mode の分類器でチェックされます。
  • 送信されるメッセージは専用の分類器が 1 件ずつチェックし、カード番号や政府発行の身分証明書の情報は共有を拒否します。健康や個人の財務に関する情報は、ユーザーが明示的に求めた場合にだけ送信されます。
  • プロンプトインジェクションへの対策は、Anthropic のブラウザ操作に関する研究に基づいています。レッドチームと外部の企業がシステムをテストしており、Anthropic の公開バグバウンティの対象にもなっています。
  • Link での支払いにはバーチャルカードが使われるため、実際のカード番号は共有されません。また、Link は支払いのたびに承認を求めます。

Claude Duet の料金と利用条件

プラン月額料金Claude Duet
Claude Free$0発表では言及なし
Claude Pro$20.00、年払いは $16.67プレビューに含まれる（ウェイトリスト制）
Claude Max 5x$100.00プレビューに含まれる（ウェイトリスト制）
Claude Max 20x$200.00プレビューに含まれる（ウェイトリスト制）
Claude Team1 シートあたり $25.00まだ利用できない

利用は米国の Pro・Max 加入者から始まり、招待は段階的に送られます。Anthropic は、ほかの国や Team・Enterprise プランでの提供時期を示していません。

Claude Duet は、プランの利用上限をチャットや Claude Code と共有します。バックグラウンドのチェックも上限に算入され、財務モデルやスライド資料のような大きな作業はモデルのターン数が増えます。1 回のチェックやタスクでどれだけ消費するかを Anthropic は公開していません。9to5Mac は、バックグラウンドの作業によってチャットだけの場合より早く上限に達することがあるという Anthropic の注意書きを伝えています。

参考までに、Anthropic の API での Claude Opus 5.5 の価格は 100 万トークンあたり入力 $4.00、出力 $20.00 です。Claude Duet と Grok Bot：料金と利用上限の記事では、この単価で各プランの料金をトークン数に換算しています。

既知の制限

Anthropic はプレビュー版について次の点を挙げています。

  • スレッドを読み違えたり、何が緊急かを見誤ったりすることがあります。
  • 中核の機能は仕事向けに作られているため、チケットの予約のような個人の用事は得意ではありません。
  • ブラウザの画面はまだ見られません。
  • メインの Claude アプリとは別のアプリです。
  • 1Password に保存したログイン情報でのサインインと、Shopify ストアフロントのビジュアルエディターは、今後対応予定とされています。

よくある質問

Claude Duet とは何ですか？

Claude が能動型エージェントとして動く Anthropic のアプリです。朝のブリーフィングを送り、数時間おきに連携アプリを確認し、専用のクラウド上のコンピューターでタスクを処理し、ユーザーの代わりに操作する前に確認を求めます。

Claude Duet は無料ですか？料金はいくらですか？

個別の料金はかかりません。リサーチプレビューの期間中は Claude Pro（月額 $20.00）と Claude Max に含まれ、Claude のほかの機能と同じ利用上限を使います。

Claude Duet を使えるのは誰ですか？ウェイトリストはありますか？

米国の Pro・Max 加入者で、ウェイトリストを通じて利用できます。Team と Enterprise プランはまだ対象外で、ほかの国での提供は発表されていません。

Claude Duet はどのモデルを使っていますか？

Anthropic によると、Claude Opus 5.5 を中心に設計されています。

Claude Duet が確認なしでできることは何ですか？

読む、下書きする、作業を準備することはできます。メッセージの送信、支払い、署名、削除には承認が必要で、証券の売買や口座間の送金はブロックされます。

スマートフォンの電源を切っても Claude Duet は作業を続けますか？

はい。タスクは専用ブラウザを備えた仮想マシン上で実行され、タスクが終わったときや確認が必要なときに通知が届きます。

Claude Duet は Claude アプリとどう違いますか？

Claude アプリはプロンプトに応答します。Claude Duet は、同じメモリ、スキル、コネクタを使いながら、何をユーザーに知らせるかを自分で決め、独自のスケジュールでアカウントを確認し、バックグラウンドで作業を続けます。
