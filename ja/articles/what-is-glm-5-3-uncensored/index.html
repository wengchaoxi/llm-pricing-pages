GLM 5.3 Uncensored と GLM 5.3 Flash Uncensored とは？

重みを編集して、元のモデルより拒否を大幅に減らした GLM-5.3 の派生版 2 つです。abliteration で何が変わるか、それぞれどのモデルを基にしているか、料金、そして変わらず残る制約をまとめています。

GLM 5.3 Uncensored と GLM 5.3 Flash Uncensored は、重みが公開されている Z.ai の GLM-5.3 ファミリーをもとにしたコミュニティ版です。拒否の挙動を重みのレベルで弱めており、コミュニティではこの処理を abliteration と呼んでいます。Z.ai の公式リリースではなく、Z.ai がホストしているわけでもありません。

要点

  • GLM 5.3 Flash Uncensored は、GLM-5.3-Flash（総パラメータ 320B、アクティブ 18B、ネイティブマルチモーダル、MIT ライセンス）の拒否を減らした版です。100 万トークンあたり入力 $0.20、出力 $0.80 で、画像入力に対応し、コンテキストは 100 万トークンです。
  • GLM 5.3 Uncensored は、フル版 GLM-5.3（753B、テキストのみ）の拒否を減らした版です。100 万トークンあたり入力 $1.25、出力 $2.25 です。掲載ページでは実験的とされ、品質が安定しない場合があると記載されています。
  • ここでいう「uncensored」は、公開された重みから拒否の方向を取り除いたことを指します。そのため、元のモデルが断る多くのリクエストに答えます。それでも一部は拒否し、独自の安全レイヤーも持っていません。
  • 公式の元モデルは Z.ai の API で 100 万トークンあたり $0.15 / $0.50（Flash）と $1.40 / $4.40（フル版）です。
  • 使い方の責任は利用者にあり、利用するサービスの規約とお住まいの地域の法律に従います。

ここでいう「uncensored」とは

元の GLM-5.3 は重みが公開されており、拒否の仕組みも組み込まれています。明らかに有害なことを頼むと、たいてい断ります。重みが公開されているため、誰でも編集できます。よく使われる手法が abliteration です。モデルの活性化の中から拒否に対応する内部の方向を見つけ、それを残差ストリームから差し引くことで、モデルは拒否を出力しなくなり、それ以外の挙動はおおむね保たれます。Anthropic は検証のために独自の abliteration 版を作り、有害リクエストに関する 3 つのベンチマークで GLM-5.3 の拒否率が 90% 超からおよそ 2〜12% に下がった一方、一般的な科学の評価のスコアは変わらなかったと報告しています。ある Flash 版についてのベンダーの数字も、規模は小さいながら同じ傾向を示しています。悪意のある指示のセットで、拒否は 96% から 11% に下がりましたが、ゼロにはなっていません。

これは重みへの恒久的な変更で、推論時に入力するジェイルブレイクのプロンプトでも、取り外せるアダプターでもありません。付け外しするものがないため、プロンプトやアダプターを調べても abliteration 済みのモデルかどうかは確認できません。Hugging Face で最も早い GLM-5.3-Flash のリポジトリは、重みが公開された当日の 2026年8月26日に作られ、フル版で最も早いものは重みの公開翌日の 8月29日に作られています。その後、複数のグループが FP8、GGUF、EXL3、NVFP4 形式のビルドを公開しています。フル版のチェックポイントは数百 GB（FP8 で約 756 GB、3 ビット EXL3 で約 273 GB）あるため、自前で動かすにはデータセンター向けの GPU が必要です。Flash はそれより軽く、FP8 で約 331 GB です。

2 つの元モデル

2 つの uncensored 版が異なるのは、出発点が異なるからです。GLM-5.3-Flash とフル版 GLM-5.3 は別々のモデルで、大きなモデルとその蒸留版という関係にはありません。

この点でフル版はより重い意味を持ちます。Z.ai は 8 月の発表後、サイバー能力を理由に重みの公開を 2 週間見送りました。その後 Anthropic と NIST の CAISI はいずれも、これまでで最もサイバー能力の高いオープンウェイトモデルであり、簡単に回避できる安全対策のまま公開されたと評価しています。こうしたモデルから拒否を取り除くことになるため、特にフラッグシップの uncensored 版は慎重に扱う必要があります。

公式の元モデルと比べると、2 つは逆の位置にあります。Flash Uncensored は公式の Flash API（$0.15 / $0.50）より少し高く、その差は拒否を減らした版に上乗せされた分です。フル版の GLM 5.3 Uncensored は公式フラッグシップの従量料金（$1.40 / $4.40）より安く、これは Z.ai 自身のエンドポイントではなくコミュニティのビルドだからです。最新の料金とホストの一覧は各モデルのページにあります。

どちらを選ぶか

多くの人が選ぶのは Flash Uncensored です。安く、マルチモーダルで速く、100 万トークンのコンテキストがあり、Flash の画像入力を保ったまま拒否が減っています。フル版の GLM 5.3 Uncensored では、フラッグシップの強いテキスト推論と 131K という大きな出力上限が得られますが、料金は数倍で、画像入力はなく、掲載ページでは実験的で出力が安定しない場合があるとされています。たいていの作業では公式の元モデルのほうが安く、挙動も予測しやすいです。uncensored 版が役に立つのは、元のモデルの拒否が正当な作業を妨げる場面に限られます。たとえばレッドチーミング、安全性や拒否の仕組みの研究、コンテンツモデレーション用データセットの構築、慎重すぎるフィルターに引っかかるフィクションなどです。

注意点

  • 安全対策が弱い。これらのビルドは元のモデルが断るリクエストに答え、独自のモデレーションもありません。必要なフィルタリングは自分で追加します。
  • 責任と法律。利用にはホストの規約と、お住まいの地域の法律が適用されます。拒否が減っても、そのどちらも任意にはなりません。
  • 信頼性。フル版 Uncensored の掲載ページでは実験的とされています。コミュニティからは、abliteration 済みの GLM ビルドが最高の推論レベルで難しいプロンプトに当たると、推論の予算を使い切って何も返さなかったり、ループしたりすることがあるという報告があります。
  • 出どころ。これらはコミュニティによる重みの編集で、Z.ai の監査を受けておらず、アップロードごとに手法も品質も異なります。
  • サイバー面の背景。フラッグシップの GLM-5.3 は、エクスプロイトの作成能力が高く、組み込みの安全対策が弱いと評価されています。拒否を取り除くとこのリスクが広がります。これが、フル版の uncensored ビルドを慎重に扱うべき主な理由です。

よくある質問

GLM 5.3 Uncensored は Z.ai の公式モデルですか？

いいえ。Z.ai がオープンウェイトで公開している GLM-5.3 を、コミュニティが重みを編集して作ったものです。Z.ai は独自のライセンスで元のモデルを公開していますが、uncensored 版の公開もホスティングもしていません。

GLM 5.3 Uncensored と GLM 5.3 Flash Uncensored の違いは何ですか？

Flash Uncensored は総 320B・アクティブ 18B のマルチモーダルモデル GLM-5.3-Flash をもとにしているため、より安く、画像を入力できます。無印の GLM 5.3 Uncensored はフル版 753B の GLM-5.3 をもとにしており、テキストのみですが、推論が強く、料金も高めです。

料金はいくらですか？

100 万トークンあたり、Flash Uncensored は入力 $0.20、出力 $0.80、フル版の GLM 5.3 Uncensored は入力 $1.25、出力 $2.25 です（2026年10月23日に閲覧）。最新の料金は各モデルのページにあります。

「uncensored」なら何にでも答えますか？

いいえ。abliteration は拒否率を大きく下げますが、ゼロにはしません。ある Flash 版のベンダーの数字では、悪意のある指示のセットで 96% から 11% に下がりました。abliteration を施した GLM-5.3 の独立したテストでは、残る拒否率はベンチマークによって数 % から 10% 台前半でした。

ローカルで動かせますか？

はい。ただしデータセンター向けの GPU が必要です。コミュニティのビルドは FP8、GGUF、EXL3、NVFP4 形式で公開されています。フル版のチェックポイントは数百 GB あり、Flash はそれより軽く FP8 で約 331 GB です。

使っても合法ですか？

利用にはホストの規約とお住まいの地域の法律が適用されます。安全対策が弱くても、モデルの出力に対する責任がなくなるわけではありません。
