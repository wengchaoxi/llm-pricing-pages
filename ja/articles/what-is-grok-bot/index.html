Grok Bot とは？xAI の AI チームメイトを解説

クラウド上にブラウザ、ファイル、ターミナルを持つ名前付きの Bot です。複数の Bot が並行して動き、1 回の実演からワークフローを覚え、承認が必要なときにはユーザーに確認します。

Grok Bot は xAI のエージェント製品です。xAI は現在 SpaceXSI の名前で事業を行っています。ユーザーは Bot を作成してそれぞれに名前と担当業務を与え、同僚に連絡するのと同じようにメッセージを送ります。各 Bot はブラウザ、ファイルシステム、ターミナルを備えた永続的なクラウド上のコンピューターで作業し、ユーザーが使っているツールにサインインして完成した成果物を返します。ユーザーに戻ってくるのは承認が必要なときだけです。2026年8月11日にベータ版として公開されました。

要点

  • Grok Bot では、名前付きの AI チームメイトを使えます。各 Bot は独自のメモリとコンテキストを保持し、実際に使っているツールの中で作業し、ノート PC を閉じた後も作業を続けます。
  • 複数の Bot が並行して動き、互いにメッセージを送り合い、作業を引き継げます。よくある構成は、調整役の Bot の下に、受信トレイ、経費、採用、バグ修正などを担当する専門の Bot を置く形です。
  • Bot はユーザーがワークフローを 1 回行うのを見て、それをルーティンとして保存し、スケジュールに沿って実行できます。
  • 1 つのアカウントのすべての Bot は、ファイルやログイン情報を含めて 1 台のクラウド上のコンピューターを共有します。そのため xAI のドキュメントは、Bot を分けてもセキュリティの境界にはならないとしています。
  • 2026年10月12日の X Subscription 導入以降、Grok Bot は Grok Premium（月額 $30.00）以上に含まれます。Super（$100.00）と Ultra（$200.00）では、週ごとの利用枠が Premium の 3.5 倍と 12 倍になります。

Grok Bot とは

xAI は Bot を「実際の仕事を任せられる AI チームメイト」と呼んでいます。Bot は貼り付け用の下書きを渡すのではなく、実際のツールの中で作業を完了させます。たとえば CRM のレコードを更新したり、チケットを起票したりします。

Grok Bot は社内のプロトタイプとして始まりました。xAI によると、顧客に公開する前から、社内のチームが営業のアプローチ、マーケティングキャンペーン、オフィス運営、バグ修正に使っていました。発表記事の例には、通話メモを CRM に追加してフォローアップを下書きする営業 Bot、新入社員のオンボーディングと Gmail に届く請求書の処理を行う運用 Bot、バグを再現してチケットを起票し、修正をデバッグ用の Bot に引き継ぐエンジニアリング Bot があります。

セットアップは会話で進みます。Bot を作成して仕事の内容を説明し、求められたらアクセスを許可します。同じ Bot にデスクトップアプリとモバイルアプリの両方から連絡でき、テキスト入力、音声入力、音声チャットのいずれでもやり取りできます。この機能が利用できる場合は、X の投稿で @bot をタグ付けして作業を始めることもできます。

用途

xAI の製品ページでは、ユーザーが離れている間に進む作業が紹介されています。たとえば夜のうちに営業パイプラインを作る作業では、取引先を調べ、連絡先をスコアリングし、ユーザーの文体でメールや LinkedIn のメッセージを下書きし、朝に確認するリストを残します。xAI のページにある例は次のとおりです。

役割作業の例
チーフ・オブ・スタッフほかの Bot を調整し、ユーザーが途中で止めたスレッドをフォローアップし、止まっている引き継ぎを促す
営業取引先を調べ、通話メモを CRM に追加し、承認用のアプローチ文面を下書きする
運用新入社員の受け入れを手配し、Gmail に届く請求書を処理し、経費を扱う
マーケティングキャンペーン業務と有料メディアの分析
サポートZendesk にサインインしてサポートの問い合わせキューを処理する
エンジニアリング製品の UI でバグを再現し、チケットを起票し、修正をデバッグ用の Bot に引き継ぐ
レポートユーザーの作業を 1 回見て週次レポートの作り方を覚え、その後はスケジュールに沿って作成する

xAI は採用とアカウントヘルスの管理も用途に挙げています。

Bot は人と同じようにブラウザを使うため、扱いやすい API や MCP サーバーのないサイトでも作業できます。それでもサイトが自動操作をブロックしたり、セッションを終了したり、人による操作を求めたりすることはあり、その場合 Bot はその手順をユーザーに引き渡します。

Grok Bot の仕組み

Bot は、ブラウザ、ファイルシステム、ターミナルを備えた永続的なクラウド上のコンピューターで動作します。コネクタがあるものはコネクタを使い、それ以外はコンピューター操作で対応します。xAI のドキュメントによると、これらのコンピューターは Cursor のクラウドで動いています。コンピューターはアカウントごとに 1 台で、すべての Bot がファイル、ブラウザのセッション、アプリのログインを含めて同じコンピューターを共有します。各 Bot には専用の画面があり、コンピューター操作のタスクは一度に 1 つずつ実行します。異なるユーザーの間は厳密に分離されています。

Bot は同時に作業し、互いにメッセージを送り、グループチャットでコンテキストを共有し、タスクの担当を引き継げます。チャットの間でメモを中継する必要はありません。会話は Bot ごとに分かれていますが、共有ファイルや引き継ぎを通じて Bot の間でコンテキストが受け渡されます。名前付きの Bot は、好みの設定、役割に関するコンテキスト、過去の作業の要約を保持します。

ルーティンを教えるには、ワークフローを行うときに Bot に横で見ているよう頼みます。Bot は手順をスキルまたはルーティンとして保存し、ユーザーの修正を反映して、スケジュールに沿って実行します。ドキュメントには、macOS、Windows、Linux 向けのデスクトップアプリと、iPhone、iPad、Android 向けのモバイルアプリが記載されています。

報道やガイドによると、その後、企業向けの管理機能（2026年9月3日）、Plaid による銀行口座とカードの連携（9月27日）、チーム全員がメッセージを送れる Team Bots と Bot ごとの Slack アプリ（9月28日）が追加されました。

Grok Bot の料金と利用条件

Grok Bot には単体のサブスクリプションはありません。xAI は 2026年10月12日から、Grok、Grok Bot、Cursor、X Premium をまとめた X Subscription という 1 つのプラン体系を販売しています。xAI の Grok Bot ページの記載は次のとおりです。

プラン月額料金Grok Bot
Plus$8.00記載なし
Premium$30.00週ごとの利用枠付きで含まれる
Super$100.00Premium の 3.5 倍の利用量
Ultra$200.00Premium の 12 倍の利用量

対象となる Teams と Enterprise プランにも含まれます。利用量は毎週リセットされます。xAI は利用枠を倍率でしか示していないため、1 週間あたりのタスク数やトークン数は公開されていません。

8月の公開時は SuperGrok と Cursor のサブスクリプションを通じて利用する形で、xAI は Bot の利用量が Grok や Cursor のチャットの利用量とは別だと説明していました。xAI のドキュメントには現在も、Cursor と連携済みの SuperGrok を経由する方法が書かれています。Cursor のプラン価格を挙げている古いガイドは、バンドル前の仕組みについて書かれたものです。

xAI は Bot に使われているモデルを明らかにしておらず、ドキュメントにはモデルの選択機能はないとあります。xAI の Grok 4.7 の発表では、このモデルは Grok Bot のハーネスで動くように訓練されたとしています。Grok 4.7 の xAI API での価格は、100 万トークンあたり入力 $2.00、出力 $6.00 です。

知っておきたい制限

  • 共有のコンピューター：アカウントのコンピューター上で 1 つの Bot がアクセスできるものには、すべての Bot がアクセスできます。Cookie、ファイル、認証情報を共有してはいけない作業には、別のアカウントが必要です。
  • モデルを選べない：ルーティンに使うモデルを選ぶ、固定する、切り替えることはできません。
  • ベータ版：第三者のガイドによると、利用上限にすぐ達するという声や、プラン名が分かりにくいという声があります。
  • 承認内容は読んで確認：Stripe Link での購入では、Grok Bot は販売者、合計金額、説明を記した支出リクエストを表示します。承認の対象はそのリクエストに書かれた内容なので、販売者、価格、その注文でサブスクリプションが始まらないかを確認してください。

よくある質問

Grok Bot とは何ですか？

Bot と呼ばれる名前付きの AI エージェントを作成できる xAI の製品です。Bot はクラウド上のコンピューターで作業し、アプリやウェブサイトにサインインして複数の手順からなる作業を完了させ、承認が必要なときにユーザーに戻ってきます。

Grok Bot の料金はいくらですか？

月額 $30.00 の Grok Premium、$100.00 の Super、$200.00 の Ultra に含まれ、対象となる Teams と Enterprise プランにも含まれます。Super と Ultra では、週ごとの Grok Bot の利用枠が Premium の 3.5 倍と 12 倍になります。

ノート PC を閉じても Grok Bot は作業を続けますか？

はい。作業はクラウド上のコンピューターで実行されるため、アプリ、ノート PC、スマートフォンを閉じてもタスクやスケジュール済みのルーティンは止まりません。

複数の Bot を同時に動かせますか？

はい。Bot は並行して作業し、互いにメッセージを送り、グループチャットでコンテキストを共有し、タスクを引き継ぎ合えます。

Grok Bot はどのモデルを使っていますか？

xAI はモデル名を明らかにしておらず、モデルの選択機能もありません。Grok 4.7 の発表では、このモデルは Grok Bot のハーネスで動くように訓練されたとしています。

Bot 同士は分離されていますか？

いいえ。アカウント内のすべての Bot が、ファイル、ブラウザのセッション、ログイン情報を含む 1 台のクラウド上のコンピューターを共有しています。ユーザー同士は分離されていますが、同じアカウントの Bot 同士は分離されていません。

Grok Bot はどのデバイスに対応していますか？

xAI のドキュメントには、デスクトップは macOS、Windows、Linux、モバイルは iPhone、iPad、Android と記載されています。
