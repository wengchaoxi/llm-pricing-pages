この比較の仕組み

ここに載る数値は各プロバイダーが公開するトークン単価の API 料金で、100 万トークンあたりに換算しています。基準通貨は米ドルで、他の通貨は米ドル額を日次レートで換算した参考値であり、プロバイダーが公表した金額そのものではありません。1 つのモデルを複数のプロバイダーが提供している場合、平均は取らず各社の提示価格をそのまま残します。同じモデルでもホストごとに価格・コンテキスト長・対応機能が異なることが多いためです。

総合単価は 1 つの数値でモデルを並べます。入力価格 ×0.75 に出力価格 ×0.25 を足したもので、入力と出力が 3 対 1 という利用想定に合わせています。最安の有料チャネルは $0 の枠を除外します。無料枠には通常レート制限があり、サービス品質の保証もないためです。品質スコアは、表示がある場合は Artificial Analysis によるものです。多くのモデルには独立した品質データがないため、その行では価格のみを表示します。

価格と機能のデータは models.dev から、品質と速度のデータは Artificial Analysis から集約しています。数値は目安であり変わることがあるため、チャネルを決める前は各プロバイダーの公式ページを最終的な根拠としてください。

よくある質問

2026 年で最も安い LLM API はどれですか？
1367+ モデルの比較によると、Inference の Llama 3.2 1B Instruct が総合単価で最も安く、1M トークンあたり約 $0.010 です。
LLM API のコストはどう見積もりますか？
入力トークン数にモデルの 1M トークンあたり入力価格を掛け、出力トークンも同様に計算して合算します。組み込みのコスト計算機で、任意のモデル・プロバイダーの合計を試算できます。
コンテキストウィンドウが最も大きい LLM はどれですか？
xai の Grok 4.1 Fast が最大のコンテキストウィンドウを掲げており、最大 2,000,000 トークンです。ホストごとに上限が異なり、128,000 から 2,000,000 トークンまで幅があるため、実際に使える長さは選ぶプロバイダーによって変わります。
ここではどのプロバイダーとモデルを比較していますか？
本サイトは Alibaba, Google, OpenAI, Mistral, Meta, DeepSeek などのプロバイダーにわたる 1367+ モデルを、1M トークンあたりの入力・出力・キャッシュ価格と品質ランキングとともに比較します。
