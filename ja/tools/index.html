ツール

同一の価格・ランキングデータに基づく計算と比較のツールです。

モデル比較利用可

2 個以上のモデルを 1 つの表にまとめ、値が同じ行は隠せます。

コスト計算機利用可

月間使用量とキャッシュヒット率を入力し、チャネル別に月額コストを並べます。

トークン計算 · トークナイザー横断利用可

同じテキストの token 数と費用を複数のトークナイザーで比較します。

サブスク vs API利用可

自分の使用量でサブスクリプションと従量課金 API を比較します。

AI サブスク価格利用可

ChatGPT、Claude、Gemini などコンシューマー向けサブスクリプションの料金と枠。

API · MCP利用可

価格とランキングのデータを無料の静的 JSON で提供します。コードと MCP 対応エージェント向けの例つき。

CLI 設定ガイド利用可

Claude Code、Codex CLI、Gemini CLI、Aider、opencode、Qwen Code を自分の API キーとエンドポイントにつなぐ手順。

これらのツールの用途

各計算ツールはサイト内の他の部分と同じ価格・ランキングデータで動きます。コスト計算機は月間のトークン利用量を公式チャネルと最安チャネルの両方で見積もり、キャッシュヒットは別入力にしています。キャッシュされた入力は通常の入力料金を大きく下回って課金されるためです。

トークンカウンターは、同じテキストがモデルファミリーごとに異なる分割のされ方をすることを示します。これは中国語などの CJK テキストで特に重要で、新しいトークナイザーほど1文字あたりのトークン数が少なくなります。サブスク比較は、あなたの利用量に応じて月額固定プランと従量課金 API を比較し、単一の損益分岐点ではなく範囲として示します。
