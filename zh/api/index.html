API · MCP 接口

本站背后归一化的价格、能力与榜单数据以纯静态 JSON 开放，免费拉取、无需密钥。可以让你的代码或 agent 直接读取。

端点

GETmodels.jsonhttps://llmpricing.dev/api/models.json

全部模型：canonical 条目、官方 + 最低渠道价、综合单价、上下文、能力、Artificial Analysis 分数与 30 天用量。

GETproviders.jsonhttps://llmpricing.dev/api/providers.json

全部服务商：名称、分层（第一方 / 云平台 / 网关）、模型数、SDK、API base 与文档。

GETllms.txthttps://llmpricing.dev/llms.txt

面向 AI 抓取的纯文本站点摘要（llms.txt 约定）。

以静态文件经 CDN 提供。站点不设按客户端的配额，但托管方的常规流量限制仍然适用，请缓存响应，不要每次请求都重新拉取。数据在每次构建时刷新。

关键字段（models.json）

id, name, lab, kindCanonical id、展示名、实验室与模型类型。
official / blendedOfficial厂商自营 API 的报价（provider、modelId、每 1M token 的输入/输出/缓存读价）及其综合单价；未收录官方 API 价格时为 null。此时 reference 会回退到第三方渠道，并以 reference.official = false 标明。
reference / cheapest参考（官方/牌价）与最低付费渠道，各含每 1M token 的输入/输出/缓存读价。
outputModalities / generationPrices价格按各厂商公布的计费单位展示，计费对象与适用条件共同决定费用；这些数值不参与文本 token 单价比较。
blendedRef / blendedMin / blendedTrusted综合单价（输入×0.75 + 输出×0.25），分参考、最低、最低可信（排除网关）三种渠道。
context, outputLimit, capabilities上下文窗口、最大输出，以及三态能力位（true/false/null）。
aa (idx, coding, agentic, speed, taskCost, evals)Artificial Analysis 智能、编码、Agent 指数、输出速度与每任务成本。Free API 不含逐项评测，兼容字段 evals 固定为 null。
usage (rank, tokens, share)OpenRouter 30 天用量排名、总 token 与占比（未追踪为 null）。
hostCount, spread有多少家服务商托管该模型，以及跨平台价差。
status, openWeights, releaseDate, lastUpdated, url生命周期状态、是否开放权重、发布与最后更新日期，以及模型页链接。

示例

用 curl + jq 取综合单价最低的 5 个模型：

curl -s https://llmpricing.dev/api/models.json \
  | jq '.models
        | map(select(.blendedMin != null))
        | sort_by(.blendedMin)[:5]
        | .[] | {name, blendedMin, cheapest: .cheapest.provider}'

JavaScript（fetch）：

const res = await fetch("https://llmpricing.dev/api/models.json");
const { meta, models } = await res.json();

// 5 cheapest by blended price (input x0.75 + output x0.25)
const cheapest = models
  .filter((m) => m.blendedMin != null)
  .sort((a, b) => a.blendedMin - b.blendedMin)
  .slice(0, 5);

console.log(meta.syncedAt, cheapest);

Python（requests）：

import requests

data = requests.get("https://llmpricing.dev/api/models.json").json()
models = data["models"]

# highest Artificial Analysis intelligence with a public price
ranked = sorted(
    (m for m in models if m["aa"] and m["aa"]["idx"] is not None),
    key=lambda m: m["aa"]["idx"],
    reverse=True,
)
for m in ranked[:5]:
    print(m["name"], m["aa"]["idx"], m["blendedMin"])

端点带 Access-Control-Allow-Origin: *，浏览器里也能直接跨域取用。

MCP server

由于数据是 HTTPS 上的干净 JSON，任何具备 fetch 能力的 MCP server 都能把它暴露给 agent。例如官方参考的 fetch server：

{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"]
    }
  }
}

然后让 agent 读取 https://llmpricing.dev/api/models.json。fetch 工具默认每次只返回 5000 个字符，需用 start_index 接着读，而 models.json 超过 1 MB，所以适合定向查询。预算内最便宜的模型这类批量问题，请让具备代码执行能力的 agent 运行上面的示例，或先读体量更小的纯文本摘要 llms.txt。

带类型化工具（search_models、cheapest、compare）的第一方 MCP server 已排进路线图。在那之前，上面的 JSON 端点就是稳定接口。
