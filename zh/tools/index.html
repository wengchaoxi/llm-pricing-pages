工具

基于同一份价格与榜单数据的计算、对照工具与配置教程。

模型对比可用

两个或更多模型放进同一张表，可隐藏取值相同的行。

成本计算器可用

填入月用量与缓存命中率，按渠道排出月成本。

Token 计算 · 跨分词器对比可用

同一段文本在多个分词器下的 token 数与成本。

订阅 vs API可用

按你的用量权衡订阅与按量付费 API。

AI 订阅价格可用

ChatGPT、Claude、Gemini 等消费级订阅的套餐价格与额度。

API · MCP 接口可用

价格与榜单数据以免费静态 JSON 提供，附代码示例和 agent 通过 MCP 读取的方法。

命令行工具配置教程可用

让 Claude Code、Codex CLI、Gemini CLI、Aider、opencode、Qwen Code 接入你自己的 API 密钥与端点。

工具说明

这些计算器用的是与站内其他部分相同的价格与榜单数据。成本计算器会按官方渠道与最低价渠道分别为你的每月 token 用量计价，并单列缓存命中输入，因为缓存输入的计费远低于普通输入。

token 计数器展示同一段文本在不同模型家族下的分词差异，这对中文及其他 CJK 文本尤其重要：较新的分词器每个字所需的 token 更少。订阅对比会在你的用量水平上，把每月固定套餐与按量付费 API 相权衡，结果以区间而非单一盈亏平衡点给出。
