Claude Duet 与 Grok Bot：各自多少钱，用量限制怎么算

Claude Duet（Anthropic，2026 年 10 月 21 日起研究预览）和 Grok Bot（xAI，2026 年 8 月起早期 beta）都跑在自己的云端电脑上，关掉应用后继续干活，动手之前都会先征求确认。两者都不单独售卖，都包含在消费级订阅里，所以价格就是解锁它的那档套餐的价格。

简短结论

  • Claude Duet 没有单独定价，包含在 Claude Pro（每月 US$20.00）与 Claude Max（US$100.00 或 US$200.00）里，需排候补名单，目前先开放给美国账号。
  • Grok Bot 包含在 Grok Premium（每月 US$30.00）、Super（US$100.00）、Ultra（US$200.00）以及符合条件的 Teams、Enterprise 里。Super 与 Ultra 把每周 Grok Bot 用量提高到 Premium 的 3.5 倍与 12 倍。
  • 两家都没有公布绝对的用量上限。Claude Duet 与 Claude 其余功能共用同一套限额，Grok Bot 的额度只以「基础档的倍数」表述。
  • 最低入门价：Claude Duet 对应 Claude Pro，每月 US$20.00；Grok Bot 对应 Grok Premium，每月 US$30.00。

Claude Duet：价格与用量限制

Anthropic 把 Claude Duet 定位为面向职场人士和小企业主的主动型 agent：每天早上发一份简报，每隔几小时检查已连接的账户，并在虚拟机里处理你交代的任务，所以手机或笔记本不必一直开着。研究预览期间它包含在 Pro 与 Max 里，不额外收费，并与 Claude 其余功能共用同一套用量限制。

包含 Claude Duet 的套餐

套餐月费来源
Claude ProUS$20.00/月，年付合 US$16.67/月官方页面 ↗
Claude Max 5xUS$100.00/月官方页面 ↗
Claude Max 20xUS$200.00/月官方页面 ↗

Anthropic 表示后台检查会计入套餐限额，这也是 Claude Duet 每隔几小时检查一次、而不是持续检查的原因。较大的任务，例如财务模型或演示文稿，需要更多模型轮次，消耗的额度比普通对话多。官方没有公布 Claude Duet 的绝对任务数或 token 数，实际能用多少取决于你交给它多少后台工作。

目前通过候补名单开通，先面向美国的 Pro 与 Max 用户。公告只涉及这些账户，没有给出其他套餐或地区的时间。

Claude Duet 围绕 Claude Opus 5.5 设计。Anthropic API 对 Opus 5.5 的牌价是每百万 token 输入 US$4.00、输出 US$20.00，缓存读取 US$0.20，低于 Claude Opus 5 的 US$5.00 与 US$25.00。

Grok Bot：价格与用量限制

xAI 把 Grok Bot 描述为「AI 队友」：登录你的工具，像你一样使用它们，最后交回成品。Bot 跑在同一账号下所有 Bot 共用的一台云端电脑上，多个 Bot 可以并行，你演示一次的流程可以存成 routine，按计划自动运行。

包含 Grok Bot 的套餐

套餐月费Grok Bot 用量区别来源
Grok PremiumUS$30.00/月每周额度（1×）Grok Bot 自带电脑、登录你的工具、按计划运行 routine官方页面 ↗
Grok SuperUS$100.00/月Premium 的 3.5 倍高峰时段优先使用模型官方页面 ↗
Grok UltraUS$200.00/月Premium 的 12 倍最早使用所有产品与模型官方页面 ↗

xAI 用倍数而不是绝对数字表述用量。Grok Bot 页写的是 Super 为 Premium 的 3.5 倍、Ultra 为 12 倍；定价页则以 Plus 为基准：Premium 是 Plus 的 4 倍、Super 是 15 倍，折算下来 Super 相对 Premium 是 3.75 倍。两个页面的基准不同，Ultra 也只出现在 Grok Bot 页上。

符合条件的 Teams 与 Enterprise 套餐同样包含 Grok Bot。定价页列有每月 US$8.00 的 Plus 档，但 Grok Bot 从 Premium 起才出现。

Grok Bot 页没有写明背后的模型，定价页写的是 Premium 含最新的 Grok 模型。本站价格目录里最新的 Grok 模型是 Grok 4.7，2026年9月21日发布，xAI API 牌价为每百万 token 输入 US$2.00、输出 US$6.00。

套餐月费按 API 牌价能换多少 token

套餐月费可以按某个模型的 API 价格折算成 token。这只是单位换算，不是额度，因为两家都没有公布套餐包含多少 token。表中使用本站通用的综合单价（输入 75%、输出 25%），不计缓存折扣；反复读取同一份上下文的 agent 循环，缓存会让实际成本更低。

为什么后台工作会改变成本

聊天套餐只在你打字时消耗额度，这类 agent 在你不操作时也在消耗。Claude Duet 每隔几小时检查已连接的账户，Anthropic 说持续检查会让套餐限额耗尽得快得多。Grok Bot 按计划运行 routine，也能同时跑多个 Bot，xAI 称之为 24/7 工作。

额度用掉多少，要看启用了多少已连接应用或定时 routine，以及每个任务有多大。Anthropic 把财务模型和演示文稿列为较重的任务。xAI 各档的主要区别是每周 Grok Bot 额度，所以你让多少个 Bot 保持忙碌，是升档的实际理由。

升级到更高档之前，先看看 agent 在后台做了什么：列出已启用的 routine 和已连接的账户。Claude Duet 允许你设置它汇报什么、多久汇报一次。

同类的其他常驻 agent

另外三个消费级 agent 采用同样的形态：一台你离开后仍在工作的云端电脑。三者都早于 Claude Duet 发布。常驻型 AI agent 解读把这五款放在一起对比。

怎么选

  • 你在美国、已订阅 Claude Pro 或 Max，想要一个沿用你 Claude 记忆、技能和连接器的助手：预览期间 Claude Duet 不额外收费，在你现有的限额内运行。
  • 你想让多个 agent 并行工作、用演示来教 routine，或者要桌面端：选 Grok Bot，每月 US$30.00 起。
  • 只比价格：Claude Pro 的 US$20.00 入门价更低，但 Claude Duet 需要排候补，且先面向美国。Grok Premium 的 US$30.00 已包含 Grok Bot，xAI 页面提供随套餐下载。

常见问题

Claude Duet 免费吗？

没有单独列出费用。研究预览期间，Claude Duet 包含在 Claude Pro（每月 US$20.00）与 Claude Max（US$100.00 或 US$200.00）里，与 Claude 其余功能共用用量限制，通过候补名单先开放给美国用户。

Grok Bot 多少钱？

Grok Bot 包含在 Grok Premium（每月 US$30.00）、Super（US$100.00）与 Ultra（US$200.00）里。按 xAI 的 Grok Bot 页，Super 与 Ultra 把每周用量提高到 Premium 的 3.5 倍与 12 倍。符合条件的 Teams 与 Enterprise 套餐也包含它。

哪些 Claude 套餐包含 Claude Duet？

Anthropic 的公告只提到 Claude Pro 与 Claude Max，没有提到 Free、Team 或 Enterprise 套餐。

Claude Duet 会占用我的 Claude 用量限制吗？

会。它与 Claude 其余功能共用套餐限额，后台检查会计入，财务模型、演示文稿这类较大的任务比普通对话消耗更多。

Claude Duet 用的是什么模型？

Anthropic 表示 Claude Duet 围绕 Claude Opus 5.5 设计，Anthropic API 对它的牌价是每百万 token 输入 US$4.00、输出 US$20.00。

Claude Duet 会自己发消息或付款吗？

不会。发送消息、付款、签署文件或删除任何内容之前，它会展示具体操作并等待你批准。买卖证券和账户间转账即使你批准也被禁止。

Claude Duet 在美国以外能用吗？

研究预览先面向美国的 Pro 与 Max 用户，通过候补名单开通。公告没有给出其他地区的时间。

电脑关机后 Grok Bot 还会继续工作吗？

按 xAI 的描述，Bot 跑在自己的云端电脑上、24/7 工作，笔记本不必一直开着。
