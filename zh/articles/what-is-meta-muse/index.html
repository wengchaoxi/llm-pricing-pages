Meta Muse 是什么？Meta 的个人 AI agent 详解

一个像给真人发消息那样使用的 agent。它围绕目标制定计划，能打开浏览器、填写表单、代你议价，并用一次性卡号付款；由独立的 Sentinel agent 批准哪些内容可以离开它的虚拟机。

Muse（常被称作 Meta Muse）是 Meta 于 2026 年 9 月 8 日发布的个人 AI agent。你在 Muse 应用或 WhatsApp 里告诉它要办什么事，它就动手去做：可以打开浏览器、填写表单、发送邮件、预订行程，并代你议价。较长的任务在你关掉应用后继续运行；情况有变或需要你批准时，Muse 会回来找你，例如发送邮件或购买东西之前。

简短结论

  • Muse 是面向日常目标与杂务的消费级 agent，涵盖邮件、出行、表单、账单、购物和计划安排，由 Meta 的 Muse Spark 模型驱动。
  • 它运行在 Muse Secure VM 上，即每位用户一台专属的云端机器，存放 agent 和你的数据。任何要发往互联网的内容，都必须经过独立的 Sentinel agent 批准。
  • 它会记住对你重要的事，也会主动提出建议。你可以让它忘掉特定的细节。
  • Muse 可以免费使用，但有每周用量上限。Power（每月 US$20.00）把额度提高到每周 5 亿 Muse token，Maximum（每月 US$100.00）提高到 30 亿。
  • 目前在美国提供，支持 iOS、Android、muse.ai 和 WhatsApp。Meta 表示即将支持 AI 眼镜。

Meta Muse 是什么

Meta 把 Muse 描述为一个安全、私密的个人 agent，帮你推进目标，也会提出想法。和它对话就像给另一个人发消息，所以除了独立应用，它也能在 WhatsApp 里使用。Meta 表示上手不需要技术背景。

你可以交给它单个任务，例如发一封邮件或预订一次旅行，也可以交给它一个更大的目标。面对目标，Muse 会帮你制定个人计划，协调你的时间和资源，然后自行推进。Meta 举的例子包括把车卖个更高的价钱、压低一笔账单，以及随着日程其他部分的变化调整训练计划。

Meta 有好几款产品共用 Muse 这个名字。Muse 是面向消费者的 agent 应用。Muse Spark 是它背后的闭源模型，开发者可以通过 Meta 的 API 调用；媒体报道给出的版本是 1.3，API 价格为每百万 token 输入 US$1.25、输出 US$4.25。Muse Glimmer 是开放权重模型，Muse Code 是在终端里运行的编程 agent。

能用它做什么

用途Muse 做什么
邮件与消息起草邮件和邀请，经你批准后发送
出行与预订预订行程和餐厅座位
表单与事务打开浏览器，完成多步骤表单
账单比较报价，代你议价
购物把菜谱变成购物清单，用 Link by Stripe 结账

Meta 用一个例子说明记忆怎么用：Muse 可以把你在 Instagram 上收藏的菜谱 reel 变成购物清单，为一场晚宴推荐菜单，并记得朋友们的饮食禁忌，再发出邀请。

2026 年 9 月 17 日发布的 Muse for Mac 让 agent 能使用 Files、Mail、Messages、Calendar 和 Notes 等本地应用，处理整理「下载」文件夹、用本地文件填写表单这类任务。本地访问需要你主动开启，删除或发送需要你批准。

Muse 如何处理安全与隐私

Meta 的设计把 agent 和你的数据放在一台隔离的机器里，并在它与网络之间再放一个 agent：

  • Muse Secure VM：每个人的 Muse 都运行在云端一台属于自己的电脑上，其他 agent 无法访问。已连接服务的数据和凭据都存放在这台机器上。
  • Sentinel：同一台机器上的另一个独立 agent，在系统层面与 Muse 隔开。Muse 的任何操作，未经 Sentinel 批准都不会发到互联网上；需要时 Sentinel 会来问你。
  • 凭据：Muse 看不到你的密码和支付方式。你提供的凭据进入安全存储，Muse 可以使用，但无法读取。
  • 批准与操作记录：发送邮件、购买东西这类敏感操作之前，Muse 会先和你确认，并完整展示它已经做了什么、接下来打算做什么。
  • 访问控制：你决定 Muse 连接哪些应用、获得多大权限，例如邮件设为只读，或设为可读可发。任何时候都可以断开某项服务。
  • 数据使用：Muse 不会把你的对话或虚拟机数据共享给 Meta 的广告系统；你也可以选择不让自己的交互数据用于训练 Meta 的模型。

付款通过 Link by Stripe 完成，它会生成一次性卡号。Meta 表示 Muse 是第一个受 Link 购买保障覆盖的 AI agent。Shop Pay 和 1Password 的支持标注为即将推出。Meta 还计划推出 Muse Confidential VM，整台机器用只有你持有的密钥加密，目前尚未上线。

Meta Muse 价格与套餐

套餐月费每周用量
FreeUS$01 亿 Muse token（据 Mark Zuckerberg 的发布帖）
PowerUS$20.005 亿 Muse token

Meta 帮助中心说明，每周额度随升档增加；免费额度用完后，可以升级套餐，也可以等额度刷新。订阅者须年满 18 岁、用 Meta 账号登录，并且身处提供 Muse 的国家。Muse 及其订阅目前处于小范围测试阶段，在美国提供。

Muse token 是 Meta 自己的用量单位。Meta 没有说明它与 Muse Spark API 的 token 如何对应，所以本站不把这份额度折算成 API 成本。GoSearch 引用的一次测试中，免费档上的一次重度使用消耗了每周额度的约 9%。

目前还缺什么

  • Muse 仅在美国提供，Meta 没有给出其他国家的时间。
  • 现有的保护措施由 Meta 运营。能把 Meta 也挡在外面的 Confidential VM 已经公布，但尚未发布。
  • 媒体测试者反映 Muse 推荐过几年前就已关门的餐厅，Business Insider 发现它只能看到 Instagram 视频的第一帧。
  • Meta 没有公布每档套餐每周支持多少个任务，也没有说明单个任务最长能运行多久。

常见问题

Meta Muse 是什么？

Meta 推出的个人 AI agent，你在 Muse 应用或 WhatsApp 里给它发消息。它在自己的云端电脑上替你执行操作，例如发送邮件、预订行程、填写表单和购买东西。

Meta Muse 免费吗？

免费，但有每周用量上限。Power（每月 US$20.00）与 Maximum（每月 US$100.00）把每周额度分别提高到 5 亿和 30 亿 Muse token。

Muse 用的是什么模型？

Meta 表示 Muse 运行在 Muse Spark 上，这是 Meta 能力最强的模型。媒体报道给出的版本是 Muse Spark 1.3。

Meta Muse 在哪里可以用？

美国，支持 iOS、Android、muse.ai 和 WhatsApp，另有 Mac 应用。Meta 表示即将支持 AI 眼镜。

Muse 会不经询问就花我的钱吗？

不会。购买之前它会先和你确认，通过 Link by Stripe 用一次性卡号付款，也看不到你保存的支付方式。

Muse 里的 Sentinel 是什么？

同一台云端机器上的另一个独立 agent，Muse 发往互联网的任何内容都必须经它批准。需要时它会征求你的许可。

Meta 会把 Muse 的数据用于广告吗？

Meta 表示 Muse 不会把你的对话或虚拟机数据共享给它的广告系统。你也可以选择不让自己的交互数据用于模型训练。
