ChatGPT dots 是什么？OpenAI 的常驻 agent 详解

ChatGPT 里一个有名字的 agent：承担持续的目标，在后台做调研，按计划执行检查，可在 4,000 多个应用里工作，并按你设定的规则决定何时直接执行、何时先问你。

ChatGPT dots（也叫 OpenAI Dots）是 ChatGPT 里的常驻型 agent，由 OpenAI 于 2026 年 9 月 29 日在 DevDay 上发布。dot 由 GPT-6 Astra 驱动，有自己的云端电脑和浏览器，通过 ChatGPT 插件连接 4,000 多个应用，并在两次对话之间继续推进你的目标。你可以在 ChatGPT、Slack 或 Microsoft Teams 里找到它，也可以和它语音通话。

简短结论

  • dot 是一个持续存在的 agent，有目标、记忆和云端电脑，并能访问你已连接的应用。你不和它对话时，它也在继续推进工作。
  • 典型用途包括定时回顾（例如每天早上的日程简报）、后台调研、在你的应用里跟进事项，以及把编程工作交给 Codex。
  • 通过 Custom Rules，你可以按操作类型决定：dot 直接执行、仅当你明确要求了这项操作时才执行、先问你，还是把这一步交给你。另有一个独立的审核 agent 在计划中的操作执行前先检查一遍。
  • 你的第一个 dot 包含在 ChatGPT Pro（每月 US$100.00 起）与 Business Premium（每席位 US$125.00）里。Free、Go 和 Plus 不包含。
  • 欧洲经济区、瑞士和英国的 ChatGPT Pro 用户无法使用 dot，Business Premium 工作区可以。

dot 是什么

ChatGPT 早先的 agent 功能是收到请求时执行一个任务，完成后就停下。dot 在不同会话之间保留它的目标、电脑、记忆和你已连接的应用，自己安排周期性检查，需要你做决定时给你发消息。OpenAI 把 dots 描述为能承担持续职责的 agent。

创建 dot 时，你给它起名字，再选一个性格。它一开始沿用你现有的 ChatGPT 记忆，之后形成自己的记忆，其中也包括来自已连接应用的内容。应用权限在 dots、ChatGPT、ChatGPT Work 和 Codex 之间共享，所以你已经连接过的应用，dot 也能使用。

没有分配任务时，dot 会主动做调研：读取你允许的信息源，并保存私有笔记。这些后台工具不能发送消息、不能修改你应用里的内容，也不能操控浏览器。时间预算设置用来引导 dot 在一项工作上花多长时间。

每个 dot 都运行在 OpenAI 的前沿模型 GPT-6 Astra 上，其 API 牌价为每百万 token 输入 US$10.00、输出 US$50.00。

能用它做什么

文档中的典型用法是一项长期职责，配上一个计划：

用途示例
周期性检查每天早上查看你的日程并发一份简报
后台调研关注客户反馈或某个话题，提示有哪些变化
跟进发现被耽搁的工作，准备好下一步等你批准
编程工作在 Codex 云端环境里创建任务，例如修复它发现的问题
购物经你批准后，用商家网站上保存的卡付款

OpenAI 发布时举的例子：一位测试者的 dot 发现他忘了给一家媒体开发票，于是准备好发票，在他批准后发了出去。进行中、已排期和已完成的工作都显示在 Activity View 里。

你还可以通过桌面应用连接自己的电脑，这项功能默认关闭。开启后，dot 可以使用本地文件和技能，云端浏览器被拦截时改用你的本地浏览器。

规则与防护

Custom Rules 规定 dot 如何处理某一类操作，共有四个选项：

选项结果
Take action without asking（不询问直接执行）dot 直接执行
Take action if pre-approved（预先批准才执行）仅当你在提示词里明确要求了这项操作时才执行
Ask before taking action（执行前先询问）dot 暂停，等你批准
Hand off to you（交给你）dot 准备好这一步，由你完成

有些操作的处理方式是固定的。修改密码或转账时，控制权交回给你。永久删除数据或安装软件可能每次都需要批准。规则可以让这些默认设置更严格，但不能比它们更宽松。

计划中的操作执行之前，一个名为 auto-review 的独立审核 agent 会对照你的指示、你的 Custom Rules 和 OpenAI 的安全要求检查一遍，例如拦下发错收件人的邮件。在支持的登录场景中，你在安全表单里输入凭据时 dot 会暂停，凭据直接传给浏览器，不会展示给模型。

OpenAI 在 GPT-6 Astra 的系统卡里公布了针对 dot 的测试结果。在一项批量邮件测试中，50,000 封邮件里混有 16,600 次提示词注入攻击，没有一次成功。越界行为（例如在互不相关的任务之间传递信息）的比例，在中间穿插的任务数从 5 个翻倍到 10 个时，从 8.6% 升到 19.7%。OpenAI 指出，这些场景是特意按高难度挑选的。

ChatGPT dots 价格与开通

套餐月费dot
ChatGPT Free、Go、PlusUS$0 至 US$20.00不包含
ChatGPT ProUS$100.00 起包含第一个 dot，欧洲经济区、瑞士和英国除外
Business Premium每席位 US$125.00，年付合 US$100.00所有支持地区均包含第一个 dot
Enterprise、Edu、Healthcare按协议Beta，管理员启用前保持关闭

dots 面向 18 岁及以上的用户，且分批推送，符合条件的账号也可能要等几天。

和 dot 的对话不计入 ChatGPT 的用量限制。发布时 OpenAI 表示，第一个月里较重的 dot 用量不计入符合条件套餐的额度，各套餐的用量条款随后公布。dot 创建的 Codex 和 ChatGPT Work 任务照常计入。OpenAI 表示，之后可以添加更多 dot，并提高 dot 的速度或每月工作额度，目前还没有公布价格。有用户在 OpenAI 论坛反映，在 Pro 上和 dot 长时间语音通话后，会收到需要暂停休息的提示。

需要了解的限制

  • 每人只有一个 dot。由多个 dot 组成的团队已在计划中，Enterprise 试点可以运行专门分工的 dot。
  • 你无法查看或删除 dot 的单条记忆。Reset 会删除这个 dot 及其对话、记忆和计划任务，它创建的文件、Codex 线程和聊天会保留。
  • 发布时 dot 没有独立的邮箱地址，也不能给你打电话。短信功能是仅限美国 Pro 用户的有限 beta。
  • OpenAI 帮助中心表示，dot 可能出错，包括在执行你设定的规则时。
  • OpenAI 的 dots 与初创公司 New Computer 早先推出的陪伴类应用 Dot 无关。

常见问题

ChatGPT dots 是什么？

ChatGPT 里的常驻型 agent。每个 dot 运行在 GPT-6 Astra 上，有自己的云端电脑和浏览器，可连接 4,000 多个应用，保有记忆，并在两次对话之间继续推进目标。

ChatGPT dots 免费吗？

第一个 dot 不额外收费，但只随 ChatGPT Pro（每月 US$100.00 起）或 Business Premium 提供。Free、Go 和 Plus 不包含 dots。

在英国或欧盟能用 ChatGPT dots 吗？

ChatGPT Pro 不行，它不覆盖欧洲经济区、瑞士和英国。Business Premium 工作区在所有支持 ChatGPT 的地区都能使用 dots。

在哪里可以和我的 dot 对话？

桌面端、网页端和移动端的 ChatGPT，Slack 和 Microsoft Teams，以及 ChatGPT 内的语音通话。美国的 Pro 用户可能获得短信 beta。

dots 会占用我的 ChatGPT 用量限制吗？

和 dot 聊天不会。发布后的第一个月，较重的 dot 工作不计入套餐额度，OpenAI 表示各套餐的条款随后公布。dot 创建的 Codex 任务照常计入。

dot 能花钱或修改密码吗？

经你批准后，它可以用商家网站上保存的卡购买。修改密码或转账时，控制权交给你来完成。

怎么删除 dot 记住的内容？

单条记忆无法编辑。Reset 会把 dot 连同它的对话、记忆和计划任务一起删除。
