Claude Duet 是什么？Anthropic 的主动型 agent 能做什么

一款独立的 Claude 应用：每天早上发简报，关注你已连接的账户，在自己的云端电脑上执行任务，发送、付款、签署或删除之前先征求同意。

Claude Duet 是 Anthropic 的一款应用，在这里由 Claude 主动开启对话，而不是等你发提示词。它会查看你连接的应用，告诉你哪些事需要处理，接手你交代的任务，关掉应用后继续在云端电脑上工作。Anthropic 于 2026 年 10 月 21 日以研究预览形式开放它，面向美国的 Claude Pro 与 Max 订阅用户，通过候补名单开通。

简短结论

  • Claude Duet 是一个主动型 agent，有自己的独立应用，支持 iOS、Android 与 claude.ai。它每天早上发一份简报，每隔几小时检查已连接的账户，有事需要你决定时给你发消息。
  • 它面向职场人士和小企业主：整理收件箱与日历、发票、工资发放、招聘帖、合同、预测、演示文稿和仪表盘。
  • 任务在带独立浏览器的虚拟机上运行，手机或笔记本可以关机。
  • 发送消息、付款、签署文件或删除任何内容之前，它会先征求同意。买卖证券和账户间转账即使你批准也被禁止。
  • 它没有单独定价，包含在 Claude Pro（每月 US$20.00）与 Max（US$100.00 或 US$200.00）里，与 Claude 其余功能共用同一套用量限制。

Claude Duet 是什么

普通的 Claude 应用在你给它写消息时回答，Claude Duet 则先开口。每天早上，它就你已连接应用里最重要的事项发一份简短的简报；白天只在有事需要你关注时才发消息。你在一条持续的对话里用文字或语音回复，所以一句话的回答和持续一周的项目都从同一个地方开始。你可以为不同主题开设单独的频道，这些频道共享同一份记忆。

Anthropic 围绕 Claude Opus 5.5 构建它，并把判断力称为它最需要的能力：判断哪些事需要你、哪些可以等，以及什么时候该先确认再行动。设置过程很短，因为 Claude Duet 沿用你 Claude 账户里的记忆、技能和已连接应用，还能搜索你过去的对话。

Claude 已经可以在 Cowork 里运行定时任务。Claude Duet 不需要事先设定任务或时间表，它自己决定把什么带到你面前。目前它是一款独立应用，与 Claude 主应用分开。

可以用它做什么

Anthropic 举的例子从零碎的行政事务到较大的项目都有。借助 Claude Marketplace 里 6,000 多个连接器和插件，Claude Duet 可以：

工作Anthropic 的例子
消息找出你漏看的 Gmail 和 Slack 消息并起草回复
账单在 QuickBooks 或 Stripe 里查找未付发票并起草催款提醒
工资在 Gusto 里准备并发放工资，工时、奖金和报销都已填好
招聘起草招聘帖，经你编辑和批准后发布到 LinkedIn
合同准备协议并通过 Docusign 发出签署
销售根据 HubSpot 里的联系人和交易记录起草跟进邮件
营销在 Canva 里把一次产品发布做成社交媒体推广活动
网店搭建、设计和管理 Shopify 店铺
采购用 Stripe 的 Link 钱包或 Shop Pay 为企业购买物品

较大的任务会以你可以审阅和编辑的文件形式交回，例如调研简报、财务或销售预测、演示文稿、仪表盘、原型或网页应用。遇到没有连接器的网站，它用自己在云端的浏览器。

Anthropic 自己的员工描述了把待办清单交给它的用法。一位在散步时和它逐条过自己的清单，另一位下班前把事情交给它，晚上在报告里看结果；开发 Claude Duet 的团队用它安排用户访谈、推进原型。

Claude Duet 如何运作

  • 云端电脑。 Claude Duet 有一台带独立浏览器的虚拟机。你用一条简短的消息描述任务，它决定用哪些应用、走哪些步骤，工作完成或需要审阅时你会收到通知。
  • 定时检查。 它每隔几小时查看一次已连接的账户，而不是持续查看，因为不间断检查会让套餐限额耗尽得快得多。你可以告诉它汇报什么、多久汇报一次。
  • Tasks 与 Make 标签页。 Tasks 标签页跟踪进行中的工作，并显示需要你处理的事项。完成的文件出现在 Make 标签页里。只有你能把任务标记为完成。
  • 共享上下文。 它使用与你 Claude 账户相同的记忆、技能和连接器，不必重复设置。

批准与安全

阅读、起草和准备工作由 Claude Duet 自己完成。发送消息、付款、签署文件或删除任何内容之前，它会展示具体操作并等待你批准。有些操作即使你批准也被禁止，包括买卖证券和账户间转账。你可以断开它有权访问的任何应用。

Anthropic 列出的其他防护措施：

  • 凭据处理沿用 Claude Managed Agents 的设计，Claude Duet 看不到你的密码或登录令牌。
  • 操作由 Claude 与 Claude Code 所用的同一个自动模式（auto mode）分类器检查。
  • 一个专用分类器检查每条外发消息，拒绝分享银行卡号或政府签发的身份证件信息。健康或个人财务信息只在你明确要求时才会发送。
  • 针对提示词注入的防御来自 Anthropic 在浏览器操作方面的研究。红队和一家外部公司测试过这套系统，它也在 Anthropic 公开漏洞赏金计划的覆盖范围内。
  • 通过 Link 付款使用虚拟卡，你的真实卡号不会被分享，而且每笔支出 Link 都会请你批准。

开通先从美国的 Pro 与 Max 订阅用户开始，邀请分批发出。Anthropic 没有给出其他国家以及 Team、Enterprise 套餐的时间。

Claude Duet 与聊天、Claude Code 共用套餐的用量限制。后台检查会计入，财务模型、演示文稿这类较大的任务需要更多模型轮次。Anthropic 没有公布单次检查或单个任务消耗多少，9to5Mac 转述了 Anthropic 的说明：后台工作可能让你比只用聊天更早触及限额。

作为参考，Claude Opus 5.5 在 Anthropic API 上的价格是每百万 token 输入 US$4.00、输出 US$20.00。Claude Duet 与 Grok Bot 对比一文按这个费率把各档套餐月费折算成了 token。

已知局限

Anthropic 为预览版列出了以下几点：

  • 可能误读邮件线程，或误判哪些事情紧急。
  • 它的核心围绕工作设计，订票这类个人事务处理得较弱。
  • 暂时不能查看它的浏览器。
  • 它是一款独立应用，与 Claude 主应用分开。
  • 用 1Password 里保存的登录信息登录，以及可视化的 Shopify 店面编辑器，被列为即将推出。

常见问题

Claude Duet 是什么？

Anthropic 的一款应用，Claude 在其中作为主动型 agent 工作。它每天早上发简报，每隔几小时检查你已连接的应用，在自己的云端电脑上处理任务，代你行动之前先征求同意。

Claude Duet 免费吗？要多少钱？

没有单独收费。研究预览期间，它包含在 Claude Pro（每月 US$20.00）与 Claude Max 里，与 Claude 其余功能共用同一套用量限制。

谁能用 Claude Duet？需要排候补名单吗？

美国的 Pro 与 Max 订阅用户，通过候补名单开通。Team 与 Enterprise 套餐暂不支持，也没有宣布其他国家。

Claude Duet 用的是什么模型？

Anthropic 表示它围绕 Claude Opus 5.5 设计。

Claude Duet 不经询问能做什么？

它可以阅读、起草和准备工作。发送消息、付款、签署和删除需要你批准，买卖证券和账户间转账被禁止。

手机关机后 Claude Duet 还会继续工作吗？

会。任务在带独立浏览器的虚拟机上运行，任务完成或需要审阅时你会收到通知。

Claude Duet 和 Claude 应用有什么不同？

Claude 应用回应你的提示词。Claude Duet 自己决定把什么带到你面前，按自己的时间表检查账户，并在后台持续工作，使用的是同一套记忆、技能和连接器。
