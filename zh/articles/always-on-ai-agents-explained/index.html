常驻型 AI agent 解读：Claude Duet、Grok Bot、Muse、dots 与 Gemini Spark

跑在自己的云端电脑上、关掉应用后继续工作、动手之前先征求确认的 agent。五款主要产品各做什么、区别在哪，以及入门要花多少钱。

2026 年 5 月到 10 月之间，五家大型 AI 公司推出了同一类产品：一个在云端有自己电脑的 agent（智能体），连接你的应用，关掉应用后继续工作，做会产生实际后果的操作之前先和你确认。Google 的版本叫 Gemini Spark，xAI 的叫 Grok Bot，Meta 的叫 Muse，OpenAI 的叫 dots，Anthropic 的叫 Claude Duet。

简短结论

  • 常驻型 agent 是带有持久运行的云端电脑、记忆、已连接应用和定时计划的聊天机器人。你不在时它继续朝目标推进，发送、购买、签署或删除之前会征求你的批准。
  • 典型用途包括早间简报、收件箱与日历整理、跟进事项、发票、价格与状态监控、预订、购买，以及以文档或演示文稿形式交付的调研。
  • 都没有单独定价。每款都包含在某个消费级订阅里，后台工作消耗的是该套餐的用量限制。
  • 入门套餐：Muse 免费，有每周用量上限；Gemini Spark 对应 Google AI Pro（US$19.99），Claude Duet 对应 Claude Pro（US$20.00），Grok Bot 对应 Grok Premium（US$30.00），dot 对应 ChatGPT Pro（US$100.00）。
  • 开放范围有限。Claude Duet 和 Muse 只在美国提供，Pro 套餐里的 dots 与 Gemini Spark 不面向欧洲经济区、瑞士和英国提供。

常驻型 agent 是什么

聊天机器人在你输入时回答，回复完就停下。编程 agent 在你的监督下于代码仓库里工作。常驻型 agent 有自己的电脑：每款产品都让 agent 运行在带浏览器的云端机器上，有些还提供文件系统和终端，你的笔记本和手机可以关机。你交给它的也可以是持续性的工作，例如每天早上查看收件箱或盯住某个价格，不只是一条提示词。

它还记得你的偏好，通过连接器或像真人一样使用浏览器，在 Gmail、Slack、CRM、日历等工具里工作。起草和准备由它自己完成，遇到难以撤销的步骤会停下来等你批准。

各厂商对同一概念用词不同：主动型 agent（Anthropic）、AI 队友（xAI）、个人 AI agent（Meta 与 Google）、常驻型 agent（OpenAI）。

用来做什么

厂商自己举的例子大致可以归为几类工作：

工作类型厂商页面上的例子
每日简报与整理Claude Duet 的早间简报；dots 每天早上查看你的日历；Spark 总结或归档订阅邮件
跟进dot 发现一张你忘了发出的发票；Claude Duet 为未付发票起草催款提醒
监控Spark 盯航班与酒店价格；Grok Bot 按计划运行 routine
多步骤事务Muse 填表、协商账单；Claude Duet 在 Gusto 里准备工资发放；Grok Bot 处理 Gmail 里的发票
预订与购买Muse 预订行程并通过 Link 付款；Claude Duet 通过 Link 或 Shop Pay 购物
工作成果Claude Duet 做的预测、演示文稿和仪表盘；Spark 生成的 Docs 文档、电子表格和 PDF；Grok Bot 以你的口吻起草外联消息
工程Grok Bot 复现 bug 并提交工单；dots 创建 Codex 任务

Claude Duet 面向职场人士和小企业主。Grok Bot 围绕一组有名字的 Bot 构建，这些 Bot 看你做一遍就能学会工作流程。Muse 面向日常生活事务，是五款中唯一有免费档的。dots 运行在 ChatGPT 内部，复用它的插件、记忆和 Codex。Gemini Spark 围绕 Gmail、Calendar 及 Google Workspace 的其余应用构建。

目前还不擅长什么

  • 登录、验证码和屏蔽机器人的网站仍然需要真人处理。每款产品都会暂停，把这些步骤交还给你。
  • Anthropic 说 Claude Duet 可能误读邮件线程或误判哪些事情紧急，OpenAI 说 dot 即使在遵守你的规则时也可能出错。
  • 在公开网页上，媒体测试者碰到过 Muse 推荐已经关门的餐厅，Spark 给出的优惠码用不了。
  • OpenAI 自己的测试里，中间穿插的任务从 5 个增加到 10 个，dots 超出任务范围的情况大约翻了一倍。
  • 多数产品先在美国上线，有几款不面向欧洲提供。

费用怎么算

五款都不单独售卖。价格就是解锁它的那档套餐的价格，agent 消耗的是该套餐的额度：

Agent包含它的套餐用量如何表述
Claude DuetPro US$20.00、Max US$100.00 或 US$200.00与 Claude 共用用量限制，后台检查也计入
Grok BotPremium US$30.00、Super US$100.00、Ultra US$200.00每周额度；Super 为 Premium 的 3.5 倍，Ultra 为 12 倍
MuseFree US$0、Power US$20.00、Maximum US$100.00每周 1 亿、5 亿或 30 亿 Muse token
dotsPro US$100.00 起，Business Premium 每席位 US$125.00与 dot 聊天不计入；首月免除额度限制，后续条款另行公布
Gemini SparkAI Pro US$19.99、Ultra US$99.99 或 US$199.99Gemini 按算力计的限额，每 5 小时刷新一次，另有每周上限

只有 Meta 公布了每周的绝对数字，而且用的是 Meta 自己的计量单位。其余几家要么以基础套餐为参照表述限额，要么完全不公布。后台工作同样计入：每隔几小时检查一次你的账户、或在夜间运行 routine 的 agent，在你没有打字时也在消耗额度。Anthropic 以此解释 Claude Duet 为什么每隔几小时检查一次，而不是持续检查。

想把套餐月费与底层模型的 API 价格对比，可以看 Claude Duet 与 Grok Bot 对比和订阅 vs API 计算器。

连接账户之前

  • 读一遍批准规则。 弄清哪些操作会不经询问直接执行。dots 允许按操作逐项设置；Gemini 在 Google Tasks 里做批量修改时不会确认。
  • 查清哪些东西是共享的。 同一账号下的所有 Grok Bot 共用一台电脑及其登录状态。dots 与 ChatGPT、ChatGPT Work 和 Codex 共用应用权限。
  • 查清记忆如何删除。 dot 的记忆只能靠重置这个 dot 清除。Muse 可以按你的要求忘掉特定细节，Gemini 允许你删除已保存的远程浏览器和电脑数据。
  • 从只读任务开始。 摘要、草稿和报告容易核对，购买、已发出的邮件和已删除的文件则不然。
  • 先观察几天额度消耗，再交派大任务，因为后台检查也计入用量。

同类的其他 agent

Every 的个人 agent 对比还涵盖了这五款之外的产品。OpenClaw 与 Nous Research 的 Hermes Agent 是开源的，可以跑在你自己的主机或托管主机上，模型由你选择。Poke 是以消息为主的助手，通过 Apple Messages、WhatsApp 和 Telegram 使用。Spear Street Technology 的 Instinct 通过短信和电话工作，目前处于内测阶段。在 Claude 和 ChatGPT 应用内部，Claude Cowork 和 ChatGPT Work 负责处理涉及你的文件和已连接工具的多步骤任务。

常见问题

什么是常驻型 AI agent？

一种拥有自己的云端电脑、记忆和已连接应用的 AI agent。关掉应用后它继续朝目标工作，按计划执行检查，做会产生实际后果的操作之前征求你的批准。

哪款常驻型 agent 最便宜？

Muse 有带每周用量上限的免费档。在付费入门套餐中，Gemini Spark 对应的 Google AI Pro（US$19.99）和 Claude Duet 对应的 Claude Pro（US$20.00）最低，其次是 Grok Premium（US$30.00）和 ChatGPT Pro（US$100.00）。

哪些能在美国以外使用？

Gemini Spark 在支持 Gemini 应用的地区均可使用，欧洲经济区、尼日利亚、瑞士和英国除外。dots 的 Business Premium 版本在 ChatGPT 支持的所有地区提供，Pro 版本在欧洲经济区、瑞士和英国以外提供。xAI 的 Grok Bot 页面没有为这款 agent 本身列出国家限制。Claude Duet 和 Muse 只在美国提供。

这些 agent 需要我的电脑一直开着吗？

不需要。五款都在云端运行任务。Gemini Spark 也可以使用你本地的 Chrome，这种模式下设备需要保持唤醒。

它们和 ChatGPT、Claude 的聊天有什么不同？

聊天在你写消息时回答，答完就停。这些 agent 持有长期目标，在你的应用里执行操作，按计划运行，需要你做决定时会给你发消息。

把它们连接到邮箱安全吗？

每家厂商都列出了防护措施，例如批准步骤、凭据隔离和提示词注入防御，也都表示 agent 可能出错。先从只读任务开始，发送和购买保持需要批准，只连接任务需要的账户。

它们用的是什么模型？

Claude Duet 用 Claude Opus 5.5，dots 用 GPT-6 Astra，Muse 用 Muse Spark，Gemini Spark 发布时基于 Gemini 3.5。xAI 没有写明 Grok Bot 背后的模型。
