API · MCP

Bu sitenin arkasındaki normalleştirilmiş fiyat, yetenek ve sıralama verileri düz statik JSON olarak yayımlanır; API anahtarı gerekmeden ücretsiz çekilebilir. Kodunuz veya bir ajan doğrudan bu veriye bakabilir.

Uç noktalar

GEThttps://llmpricing.dev/api/models.json

Tüm modeller: kanonik giriş, resmî + en ucuz kanal fiyatı, harmanlanmış fiyatlar, bağlam, yetenekler, Artificial Analysis puanları ve 30 günlük kullanım.

GEThttps://llmpricing.dev/api/providers.json

Tüm sağlayıcılar: ad, kademe (birinci taraf / bulut / ağ geçidi), model sayısı, SDK, API tabanı ve dokümanlar.

GEThttps://llmpricing.dev/llms.txt

Yapay zeka tarayıcıları için düz metin site özeti (llms.txt geleneği).

Bir CDN üzerinden statik dosyalar olarak sunulur. Site istemci başına kota uygulamaz, ancak barındırıcının genel trafik sınırları geçerlidir; bu yüzden yanıtları her istekte yeniden çekmek yerine önbelleğe alın. Veriler her derlemede yenilenir.

Anahtar alanlar (models.json)

id, name, lab, kindKanonik kimlik, görünen ad, laboratuvar ve model türü.
official / blendedOfficialLaboratuvarın kendi API fiyatı (provider, modelId, 1M başına girdi/çıktı/önbellek-okuma) ve harmanlanmış birim fiyatı; kayıtlı resmî API fiyatı yoksa null. Bu durumda reference üçüncü taraf bir kanala geri döner ve reference.official = false ile işaretlenir.
reference / cheapestReferans (resmî/liste) ve en ucuz ücretli kanal, her biri 1M token başına girdi/çıktı/önbellek-okuma ile.
outputModalities / generationPricesFiyatlar her sağlayıcının faturalandırma birimini kullanır. Faturalanan medya ve belirtilen koşullar maliyeti belirler; bu değerler metin token fiyat karşılaştırmalarına girmez.
blendedRef / blendedMin / blendedTrustedReferans, en ucuz kanal ve en ucuz güvenilir kanal (ağ geçitleri hariç) için harmanlanmış birim fiyat (girdi×0,75 + çıktı×0,25).
context, outputLimit, capabilitiesBağlam penceresi, maksimum çıktı ve üç durumlu yetenek bayrakları (true/false/null).
aa (idx, coding, agentic, speed, taskCost, evals)Artificial Analysis zeka, kodlama ve ajansal endeksleri, çıktı hızı ve görev başına maliyet. Free API benchmark bazında değerlendirme içermez; evals null olarak kalır.
usage (rank, tokens, share)OpenRouter 30 günlük kullanım sırası, toplam token ve pay (izlenmediğinde null).
hostCount, spreadModeli kaç sağlayıcının barındırdığı ve platformlar arası fiyat dağılımı.
status, openWeights, releaseDate, lastUpdated, urlYaşam döngüsü durumu, açık ağırlık işareti, yayın ve son güncelleme tarihleri ve model sayfasının URL'si.

Örnekler

Karma fiyata göre en ucuz beş model, curl ve jq ile:

curl -s https://llmpricing.dev/api/models.json \
  | jq '.models
        | map(select(.blendedMin != null))
        | sort_by(.blendedMin)[:5]
        | .[] | {name, blendedMin, cheapest: .cheapest.provider}'

JavaScript (fetch):

const res = await fetch("https://llmpricing.dev/api/models.json");
const { meta, models } = await res.json();

// 5 cheapest by blended price (input x0.75 + output x0.25)
const cheapest = models
  .filter((m) => m.blendedMin != null)
  .sort((a, b) => a.blendedMin - b.blendedMin)
  .slice(0, 5);

console.log(meta.syncedAt, cheapest);

Python (requests):

import requests

data = requests.get("https://llmpricing.dev/api/models.json").json()
models = data["models"]

# highest Artificial Analysis intelligence with a public price
ranked = sorted(
    (m for m in models if m["aa"] and m["aa"]["idx"] is not None),
    key=lambda m: m["aa"]["idx"],
    reverse=True,
)
for m in ranked[:5]:
    print(m["name"], m["aa"]["idx"], m["blendedMin"])

Uç noktalar Access-Control-Allow-Origin: * gönderir, bu yüzden tarayıcıdan da çalışır.

MCP sunucusu

Veriler HTTPS üzerinden temiz JSON olduğundan, fetch yapabilen herhangi bir MCP sunucusu bunu bir ajana sunabilir. Örneğin, referans fetch sunucusu:

{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"]
    }
  }
}

Ardından ajandan https://llmpricing.dev/api/models.json adresini okumasını isteyin. fetch aracı varsayılan olarak çağrı başına 5.000 karakter döndürür ve start_index'ten devam eder; models.json ise 1 MB'tan büyüktür, bu yüzden belirli sorgulara uygundur. Bütçe içindeki en ucuz model gibi toplu sorular için kod çalıştırabilen bir ajanda yukarıdaki örnekleri çalıştırın ya da daha küçük bir metin özeti olan llms.txt ile başlayın.

Tipli araçlara sahip (search_models, cheapest, compare) birinci taraf bir MCP sunucusu yol haritasında. O zamana kadar yukarıdaki JSON uç noktaları kararlı arabirimdir.
