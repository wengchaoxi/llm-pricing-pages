What is Grok Bot? xAI's AI teammates explained

LLM Pricing·Yayın: 11 Ağu 2026·Güncelleme: 22 Eki 2026·1.463 kelime·6 dk okuma

Named Bots with a browser, files and a terminal in the cloud, several working in parallel, learning workflows from a single demonstration and checking back when they need approval.

Grok Bot is an agent product from xAI, which now operates under the SpaceXSI name. You create Bots, give each one a name and a job, and message them the way you would message a colleague. Each Bot works on a persistent cloud computer with a browser, a file system and a terminal, signs in to the tools you use and returns finished work, coming back to you only when something needs approval. It launched in beta on Aug 11, 2026.

Facts come from xAI's launch post, product page and documentation, plus independent guides, linked under Sources. For a price comparison with Anthropic's agent, see Claude Duet vs Grok Bot.

Short answer

  • Grok Bot gives you named AI teammates. Each Bot keeps its own memory and context, works in your real tools and keeps going after you close your laptop.
  • Several Bots can run in parallel, message each other and hand work between themselves. A common setup is one coordinating Bot over specialists for inbox, expenses, recruiting or bug fixes.
  • A Bot can watch you do a workflow once, save it as a routine and run it on a schedule.
  • All Bots on one account share a single cloud computer, including its files and logins, so xAI's docs say not to treat separate Bots as a security boundary.
  • Since the Oct 12, 2026 X Subscription, Grok Bot is included from Grok Premium ($30,00 a month). Super ($100,00) and Ultra ($200,00) raise the weekly allowance to 3.5× and 12× Premium.

What Grok Bot is

xAI calls Bots "AI teammates you can give real work to". The idea is that a Bot finishes the job inside the actual tool, for example a CRM record updated or a ticket filed, instead of handing you a draft to paste.

Grok Bot began as an internal prototype. xAI says teams inside the company used it for sales outreach, marketing campaigns, office operations and bug fixes before it opened to customers. Examples from the launch post include a sales Bot that adds call notes to the CRM and drafts follow-ups, an operations Bot that onboards new hires and processes invoices from Gmail, and an engineering Bot that reproduces a bug, files the ticket and hands the fix to a debugging Bot.

Setup is a conversation. You create a Bot, describe the job and grant access when it asks. The same Bot is reachable from the desktop and mobile apps, and you can type, dictate or start a voice chat. You can also start work from X by tagging @bot in a post, where that feature is available.

What you can use it for

xAI's product page describes jobs that run while you are away, such as building a sales pipeline overnight: researching accounts, scoring contacts, drafting email and LinkedIn messages in your voice and leaving a review list for the morning. Examples from xAI's pages:

xAI also lists recruiting and account health among its use cases.

Because Bots use a browser like a person, they can work in sites that have no clean API or MCP server. A site can still block automation, end a session or require a human step, and in those cases the Bot hands the step to you.

How Grok Bot works

Bots run on a persistent cloud computer with a browser, file system and terminal. They use connectors where they exist and computer use for everything else. xAI's docs say these computers run in Cursor's cloud. There is one computer per account: all of your Bots share it, including files, browser sessions and app logins. Each Bot gets its own screen and runs one computer-use task at a time. Between different users, isolation is strict.

Bots can work at the same time, message each other, share context in group chats and pass ownership of a task, so you do not have to relay notes between chats. Conversations stay separate per Bot, while shared files and handoffs move context between them. A named Bot keeps its preferences, role context and summaries of past work.

To teach a routine, ask a Bot to follow along while you do the workflow. It saves the steps as a skill or routine, takes your corrections and runs it on a schedule. The docs list desktop apps for macOS, Windows and Linux and mobile apps for iPhone, iPad and Android.

Later additions reported by press and guides include enterprise admin controls (Sep 3, 2026), bank and card account linking through Plaid (Sep 27) and Team Bots that a whole team can message, with a Slack app per Bot (Sep 28).

Grok Bot price and access

Grok Bot has no standalone subscription. Since Oct 12, 2026, xAI sells one plan family, the X Subscription, that bundles Grok, Grok Bot, Cursor and X Premium. On xAI's Grok Bot page:

Plus$8,00Not listed
Premium$30,00Included, with a weekly allowance
Super$100,003.5× Premium usage
Ultra$200,0012× Premium usage

Eligible Teams and Enterprise plans include it too. Usage resets weekly. xAI states allowances only as multiples, so there is no published number of tasks or tokens per week.

At launch in August, access came through SuperGrok and Cursor subscriptions, and xAI said Bot usage was separate from Grok and Cursor chat usage. xAI's docs still describe the Cursor and linked SuperGrok route, so older guides that quote Cursor plan prices describe the pre-bundle setup.

xAI does not name the model behind Bots, and the docs say there is no model picker. xAI's Grok 4.7 announcement says the model was trained to work with the Grok Bot harness. Grok 4.7 costs $2,00 input and $6,00 output per 1M tokens on xAI's API.

Limits to know

  • Shared computer. Anything one Bot can reach on the account's computer, every Bot can reach. Jobs that must not share cookies, files or credentials need separate accounts.
  • No model choice. You cannot pick, pin or swap the model for a routine.
  • Beta. Independent guides report users hitting usage limits quickly and finding plan names confusing.
  • Approvals need reading. For purchases through Stripe Link, Grok Bot shows a spend request with merchant, total and description. The approval covers what you read on that request, so check the merchant, price and whether the order starts a subscription.

Frequently asked questions

What is Grok Bot?

An xAI product for creating named AI agents, called Bots, that work on a cloud computer, sign in to your apps and websites, finish multi-step jobs and come back when they need your approval.

How much does Grok Bot cost?

It is included in Grok Premium at $30,00 a month, Super at $100,00 and Ultra at $200,00, and in eligible Teams and Enterprise plans. Super and Ultra raise the weekly Grok Bot allowance to 3.5× and 12× Premium.

Does Grok Bot keep working when my laptop is closed?

Yes. Work runs on the cloud computer, so closing the app, your laptop or your phone does not stop a task or a scheduled routine.

Can several Bots work at once?

Yes. Bots can work in parallel, message each other, share context in group chats and hand tasks to one another.

Which model does Grok Bot use?

xAI does not name one and offers no model picker. The Grok 4.7 announcement says that model was trained to work with the Grok Bot harness.

Are my Bots isolated from each other?

No. All Bots on your account share one cloud computer with its files, browser sessions and logins. Users are isolated from each other, Bots on the same account are not.

Which devices does Grok Bot support?

xAI's docs list macOS, Windows and Linux on desktop and iPhone, iPad and Android on mobile.
