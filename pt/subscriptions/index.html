Preços de assinaturas de IA

Preços e cotas dos planos do ChatGPT, Claude, Gemini e outras assinaturas de IA de consumo. São cobrados por usuário ao mês, um eixo diferente da cobrança por token das APIs. Dentro de cada fornecedor, os planos são listados por preço.

Preços e limites são informações públicas coletadas em 2026-08-08 e não verificadas com cada fornecedor individualmente. Os planos mudam com frequência; a página oficial prevalece. Para avaliar uma assinatura em relação à API por uso, utilize a Calculadora de assinatura vs API →
